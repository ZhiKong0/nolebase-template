# IIC通信协议详解

## 一、IIC协议概述

### 1.1 什么是 IIC

**IIC**（Inter-Integrated Circuit，也称 I2C）是由 Philips 公司开发的一种**同步串行通信协议**，主要用于连接低速外设到处理器或微控制器。

### 1.2 IIC 的主要特点

| 特性 | 说明 |
|------|------|
| **双线制** | 只需 SCL（时钟线）和 SDA（数据线）两根线 |
| **多主从结构** | 支持一主多从，也支持多主模式 |
| **同步通信** | 时钟由主机产生，数据传输与时钟同步 |
| **半双工** | 同一时刻只能单向传输 |
| **开漏输出** | 总线采用开漏+上拉电阻结构，实现"线与"功能 |
| **地址寻址** | 7位或10位从机地址，最多支持128个设备 |

### 1.3 硬件连接示意图

```
         ┌─────────┐
    ┌────┤  主机   ├────┐
    │    │ (MCU)   │    │
SCL ├────┤         ├────┼──────┬──────┐
    │    └─────────┘    │      │      │
SDA ├───────────────────┼──────┼──────┤
    │                   │      │      │
    │    ┌─────────┐    │  ┌───┴───┐ ┌┴─────┐
    └────┤ 从机1   ├────┘  │ 从机2 │ │从机N │
         │ (OLED)  │       │(EEPROM)│ │(传感器)│
         └─────────┘       └───────┘ └──────┘
                  │
                  │
              ┌───┴───┐
              │上拉电阻│
              │(4.7kΩ)│
              └───┬───┘
                  │
                 VCC
```

## 二、物理层规范

### 2.1 电气特性

| 参数 | 标准模式 | 快速模式 | 高速模式 |
|------|----------|----------|----------|
| **时钟频率** | ≤100kHz | ≤400kHz | ≤3.4MHz |
| **SCL低电平** | ≥4.7μs | ≥1.3μs | ≥160ns |
| **SCL高电平** | ≥4.0μs | ≥0.6μs | ≥60ns |
| **SDA建立时间** | ≥250ns | ≥100ns | ≥10ns |
| **SDA保持时间** | ≥300ns | ≥300ns | ≥160ns |

### 2.2 信号电平

- **逻辑 1（高电平）**：VCC（3.3V 或 5V）
- **逻辑 0（低电平）**：GND（0V）
- **空闲状态**：SCL 和 SDA 都为高电平

### 2.3 开漏输出结构

```
        VCC
         │
        ┌┴┐
        │ │ 上拉电阻 (典型值 4.7kΩ)
        └┬┘
         ├─────── SCL/SDA 总线
         │
    ┌────┴────┐
    │   MOSFET  │ ← 开漏输出（只能拉低或释放）
    │  (开漏)  │
    └────┬────┘
         │
        GND
```

**为什么用开漏输出？**
1. **线与功能**：多个设备同时控制总线时，任意设备拉低，总线即为低
2. **电平兼容**：不同电压设备可以共存（只要上拉到最低电压）
3. **总线仲裁**：多主机模式下用于冲突检测

## 三、协议时序详解

### 3.1 起始信号（Start Condition）

**时序要求**：SCL = 1 时，SDA 从高电平跳变到低电平

```
     SDA   ────┐
              └────────
                 ↑
     SCL   ───────────────
          
        Start Condition
```

**作用**：通知所有从机，主机即将发起通信

### 3.2 停止信号（Stop Condition）

**时序要求**：SCL = 1 时，SDA 从低电平跳变到高电平

```
     SDA        ┌───────
     ────────┘
                 ↑
     SCL   ───────────────
          
         Stop Condition
```

**作用**：结束本次通信，释放总线

### 3.3 数据位传输

**时序要求**：
- SCL = 0 时：SDA 可以改变（准备数据）
- SCL = 1 时：SDA 必须保持稳定（从机采样）

```
     SDA   ───┐   ┌──────┐
              └───┘      └───┘
                D7   D6  ...  D0
     SCL   ┐   ┌───┐   ┌───┐
           └───┘   └───┘   └───
           ↑       ↑
        准备数据   采样数据
```

### 3.4 应答信号（ACK/NACK）

每个字节传输后，第 9 个时钟周期用于应答：

| 信号 | 电平 | 含义 |
|------|------|------|
| **ACK** | SDA = 0 | "收到数据，继续传输" |
| **NACK** | SDA = 1 | "不要了，停止传输" |

```
     SDA   ───────┐   ┌─────────── ACK (拉低)
              └───┘   └─────────── NACK (保持高)
                 
     SCL   ┐   ┌───┐   ┌───┐
           └───┘   └───┘   └───
                    ↑
              第9个时钟（ACK周期）
```

## 四、通信帧格式

### 4.1 完整通信过程

```
Start │ Address │ R/W │ ACK │ Data[0] │ ACK │ Data[1] │ ACK │ ... │ Data[N] │ ACK/NACK │ Stop
──────┼─────────┼─────┼─────┼─────────┼─────┼─────────┼─────┼─────┼─────────┼──────────┼──────
  S   │ 7 bits  │ 1b  │ 1b  │  8 bits │ 1b  │  8 bits │ 1b  │ ... │  8 bits │    1b    │  P
```

### 4.2 地址格式

**7位地址格式**（最常用）：
```
┌─────────┬────────┐
│ bit7~1  │  bit0  │
├─────────┼────────┤
│ 7位地址 │ R/W位  │
│(0x01~0x7F)│0=写  │
│         │1=读  │
└─────────┴────────┘
```

**示例**：OLED 地址为 `0x3C`（7位），实际发送：
- 写操作：`0x78`（`0x3C << 1 | 0`）
- 读操作：`0x79`（`0x3C << 1 | 1`）

### 4.3 重复起始（Repeated Start）

在不发送 Stop 的情况下，直接发送新的 Start，用于：
- 改变传输方向（如先写寄存器地址，再读数据）
- 连续访问不同从机

```
Start │ Addr+W │ ACK │ RegAddr │ ACK │ RepeatedStart │ Addr+R │ ACK │ Data │ NACK │ Stop
──────┼────────┼─────┼─────────┼─────┼───────────────┼────────┼─────┼──────┼──────┼──────
  S   │ 0x78   │  0  │  0x00   │  0  │      Sr       │ 0x79   │  0  │ 0xA5 │  1   │  P
```

## 五、IIC 通信的三种信号总结

| 信号 | 触发条件 | 作用 |
|------|----------|------|
| **起始信号** | SCL=1, SDA 从高到低 | 开始通信 |
| **停止信号** | SCL=1, SDA 从低到高 | 结束通信 |
| **应答信号** | 第9个时钟周期 | 数据接收确认 |

## 六、常见问题与注意事项

### 6.1 总线挂死（Bus Stuck）

**现象**：SDA 一直被拉低，无法产生起始信号

**原因**：
- 通信异常终止（如 MCU 复位时从机正发送数据）
- 从机故障

**解决方法**：
1. 发送 9 个时钟脉冲，强制从机释放 SDA
2. 发送 Stop 信号

### 6.2 上拉电阻选择

| 总线电容 | 上拉电阻值 |
|----------|------------|
| <100pF   | 10kΩ |
| 100-400pF| 4.7kΩ |
| >400pF   | 2.2kΩ |

**注意**：电阻越小，功耗越大，但上升沿越快

### 6.3 速率与距离

| 模式 | 最大速率 | 建议最大距离 |
|------|----------|--------------|
| 标准模式 | 100kHz | 1米 |
| 快速模式 | 400kHz | 0.5米 |
| 高速模式 | 3.4MHz | 0.2米 |

## 七、总结

IIC 协议的核心要点：

1. **两根线**：SCL（时钟）+ SDA（数据）
2. **三种信号**：起始、停止、应答
3. **开漏输出**：实现线与功能
4. **7位地址**：128 个从机地址
5. **同步通信**：时钟由主机控制

理解这些基础后，就可以开始编写 IIC 驱动代码了。
