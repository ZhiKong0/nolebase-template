## 一、时钟树的初始状态

### 1.1 什么是初始状态？

所谓**时钟树的初始状态**，是指单片机刚刚上电或按下复位按钮后、还没有执行任何代码时的时钟状态。了解初始状态对于后续编程至关重要。

### 1.2 初始状态的时钟配置

在初始状态下，时钟树的配置如下：

```
┌─────────────────────────────────────────────────────────────┐
│                    时钟树初始状态                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   SYSCLK (系统时钟)                                          │
│       └── 来源：HSI（内部高速时钟）                            │
│       └── 频率：8 MHz                                       │
│                                                             │
│   HCLK（AHB总线时钟）                                        │
│       └── 分频系数：/1                                      │
│       └── 频率：8 MHz                                       │
│                                                             │
│   PCLK2（APB2总线时钟）                                      │
│       └── 分频系数：/1                                      │
│       └── 频率：8 MHz                                       │
│                                                             │
│   PCLK1（APB1总线时钟）                                      │
│       └── 分频系数：/1                                      │
│       └── 频率：8 MHz                                       │
│                                                             │
│   结论：初始状态下                                          │
│   SYSCLK = HCLK = PCLK2 = PCLK1 = 8 MHz                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 验证初始状态的小实验

我们可以通过**自制延时函数**来验证初始状态。思路：利用 CPU 执行速度与时钟频率的关系，通过 for 循环实现延时。

**原理：**
- CPU 从 HCLK 获取时钟
- 初始状态下 HCLK = 8 MHz
- 假设每次 for 循环消耗 10 个 CPU 周期

**计算：**
```
每个 CPU 周期时间 = 1 / 8 MHz = 0.125 μs
每次 for 循环时间 = 0.125 μs × 10 = 1.25 μs
延时 500ms 需要的循环次数 = 500ms / 1.25μs = 400,000 次
```

**实验代码：**

```c
#include "stm32f10x.h"

int main(void)
{
    // 开启 GPIOC 时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);
    
    // 初始化 PC13（板载 LED）
    GPIO_InitTypeDef GPIO_InitStruct;
    GPIO_InitStruct.GPIO_Pin = GPIO_Pin_13;
    GPIO_InitStruct.GPIO_Mode = GPIO_Mode_Out_OD;  // 开漏输出
    GPIO_InitStruct.GPIO_Speed = GPIO_Speed_2MHz;
    GPIO_Init(GPIOC, &GPIO_InitStruct);
    
    while (1)
    {
        // 点亮 LED
        GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_RESET);
        
        // 延时 500ms（假设每次循环 10 个周期，HCLK=8MHz）
        for (volatile int i = 0; i < 400000; i++);
        
        // 熄灭 LED
        GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_SET);
        
        // 延时 500ms
        for (volatile int i = 0; i < 400000; i++);
    }
}
```

**实验现象：**
- LED 闪烁，但闪烁频率**明显比 1Hz 快**
- 这是因为实际 for 循环消耗的周期数**不等于 10**，实际约为 6 个周期左右
- 调整循环次数为 666666 次后，闪烁频率正好为 1Hz

## 二、标准库的启动代码

### 2.1 启动文件位置

启动文件位于项目目录的 `startup` 文件夹中：

```
工程目录/
├── startup/
│   └── startup_stm32f10x_md.s    ← 启动文件（汇编语言）
├── User/
│   └── main.c
└── ...
```

### 2.2 启动代码分析

在启动文件中，有一个 `Reset_Handler`，单片机复位后首先执行这里的代码：

```assembly
; Reset_Handler 代码（startup_stm32f10x_md.s）
Reset_Handler:
    ; 调用 SystemInit 函数（系统初始化）
    LDR     R0, =SystemInit
    BLX     R0
    
    ; 调用用户的 main 函数
    LDR     R0, =main
    BX      R0
```

**执行流程：**

```
单片机复位/上电
    │
    ▼
Reset_Handler（启动文件）
    │
    ├──→ SystemInit()  ← 系统时钟初始化（配置时钟树为 72MHz）
    │
    └──→ main()        ← 用户代码
```

### 2.3 SystemInit() 的作用

`SystemInit()` 函数的作用：**在 main 函数执行前，自动将时钟树配置为最高频率（72MHz）**，让芯片发挥最佳性能。

**SystemInit() 配置后的时钟树状态：**

```
┌─────────────────────────────────────────────────────────────┐
│               SystemInit() 配置后的时钟状态                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   HSE (8MHz) ──→ PLL (×9) ──→ SYSCLK = 72 MHz              │
│                                    │                        │
│   HCLK = SYSCLK / 1 = 72 MHz      │                        │
│                                    │                        │
│   PCLK2 = HCLK / 1 = 72 MHz       │                        │
│                                    │                        │
│   PCLK1 = HCLK / 2 = 36 MHz       │                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.4 禁用 SystemInit()

如果想禁用自动时钟配置，让时钟树保持在初始状态（8MHz），可以注释掉启动文件中的 `SystemInit` 调用：

```assembly
Reset_Handler:
    ; 注释掉 SystemInit 调用
    ; LDR     R0, =SystemInit
    ; BLX     R0
    
    ; 直接执行 main 函数
    LDR     R0, =main
    BX      R0
```

**注意：**
- 在汇编中，注释使用英文分号 `;`
- 不要使用中文分号，否则会报错

## 三、时钟树编程接口

### 3.1 RCC 模块简介

RCC = **Reset and Clock Control**（复位和时钟控制）

- RCC 模块有两个功能：
  1. **复位功能**：控制芯片复位
  2. **时钟功能**：控制时钟树

- **编程接口命名规则**：所有时钟相关的函数都以 `RCC_` 开头

### 3.2 编程接口一览

| 序号 | 函数名 | 功能 | 对应的时钟树节点 |
|------|--------|------|------------------|
| 1 | `RCC_HSEConfig()` | HSE（外部高速时钟）开关配置 | HSE 时钟源 |
| 2 | `RCC_HSICmd()` | HSI（内部高速时钟）开关控制 | HSI 时钟源 |
| 3 | `RCC_PLLConfig()` | PLL（锁相环）参数配置 | 锁相环 |
| 4 | `RCC_PLLCmd()` | PLL 开关控制 | 锁相环 |
| 5 | `RCC_SYSCLKConfig()` | 系统时钟来源选择 | SYSCLK |
| 6 | `RCC_HCLKConfig()` | AHB 分频器配置 | HCLK |
| 7 | `RCC_PCLK1Config()` | APB1 分频器配置 | PCLK1 |
| 8 | `RCC_PCLK2Config()` | APB2 分频器配置 | PCLK2 |
| 9 | `RCC_GetFlagStatus()` | 获取 RCC 状态标志位 | 状态查询 |
| 10 | `RCC_GetSYSCLKSource()` | 获取当前系统时钟来源 | 状态查询 |

### 3.3 各接口详解

#### 1. RCC_HSEConfig() - HSE 配置

**功能**：开启或关闭外部高速时钟（HSE）

```c
void RCC_HSEConfig(uint32_t RCC_HSE);
```

**参数：**
- `RCC_HSE_ON`：开启 HSE
- `RCC_HSE_OFF`：关闭 HSE

**示例：**
```c
RCC_HSEConfig(RCC_HSE_ON);  // 开启 HSE
```

#### 2. RCC_HSICmd() - HSI 控制

**功能**：开启或关闭内部高速时钟（HSI）

```c
void RCC_HSICmd(FunctionalState NewState);
```

**参数：**
- `ENABLE`：开启 HSI
- `DISABLE`：关闭 HSI

**注意**：初始状态下 HSI 默认是开启的

#### 3. RCC_PLLConfig() - PLL 配置

**功能**：配置锁相环的输入来源和倍频系数

```c
void RCC_PLLConfig(uint32_t RCC_PLLSource, uint32_t RCC_PLLMul);
```

**参数 1 - 输入来源：**
- `RCC_PLLSource_HSI_Div2`：HSI / 2
- `RCC_PLLSource_HSE_Div1`：HSE（不分频）
- `RCC_PLLSource_HSE_Div2`：HSE / 2

**参数 2 - 倍频系数：**
- `RCC_PLLMul_2` ~ `RCC_PLLMul_16`：2~16 倍频

**示例：**
```c
// HSE 不分频输入，9 倍频
RCC_PLLConfig(RCC_PLLSource_HSE_Div1, RCC_PLLMul_9);
```

#### 4. RCC_PLLCmd() - PLL 开关

**功能**：开启或关闭锁相环

```c
void RCC_PLLCmd(FunctionalState NewState);
```

**注意**：PLL 开启需要一定时间，需要等待就绪标志

#### 5. RCC_SYSCLKConfig() - 系统时钟配置

**功能**：选择系统时钟的来源

```c
void RCC_SYSCLKConfig(uint32_t RCC_SYSCLKSource);
```

**参数：**
- `RCC_SYSCLKSource_HSI`：选择 HSI
- `RCC_SYSCLKSource_HSE`：选择 HSE
- `RCC_SYSCLKSource_PLLCLK`：选择 PLL 输出

#### 6. RCC_HCLKConfig() - AHB 分频器配置

**功能**：配置 AHB 总线时钟分频系数

```c
void RCC_HCLKConfig(uint32_t RCC_SYSCLK);
```

**参数：**
- `RCC_SYSCLK_Div1`：SYSCLK / 1
- `RCC_SYSCLK_Div2`：SYSCLK / 2
- `RCC_SYSCLK_Div4`：SYSCLK / 4
- ...（还有 /8, /16, /64, /128, /256, /512）

#### 7. RCC_PCLK1Config() - APB1 分频器配置

**功能**：配置 APB1 总线时钟分频系数

```c
void RCC_PCLK1Config(uint32_t RCC_HCLK);
```

**参数：**
- `RCC_HCLK_Div1` ~ `RCC_HCLK_Div16`

**注意**：APB1 最高频率限制为 36MHz！

#### 8. RCC_PCLK2Config() - APB2 分频器配置

**功能**：配置 APB2 总线时钟分频系数

```c
void RCC_PCLK2Config(uint32_t RCC_HCLK);
```

**参数：**同 RCC_PCLK1Config()

**注意**：APB2 最高频率可达 72MHz

#### 9. RCC_GetFlagStatus() - 获取状态标志

**功能**：查询 RCC 模块的状态标志位

```c
FlagStatus RCC_GetFlagStatus(uint8_t RCC_FLAG);
```

**常用标志位：**
- `RCC_FLAG_HSERDY`：HSE 就绪
- `RCC_FLAG_PLLRDY`：PLL 就绪

**示例：**
```c
// 等待 HSE 就绪
while (RCC_GetFlagStatus(RCC_FLAG_HSERDY) == RESET);

// 等待 PLL 就绪
while (RCC_GetFlagStatus(RCC_FLAG_PLLRDY) == RESET);
```

#### 10. RCC_GetSYSCLKSource() - 获取时钟来源

**功能**：获取当前系统时钟的来源

```c
uint8_t RCC_GetSYSCLKSource(void);
```

**返回值：**
- `0x00`：当前时钟来源是 HSI
- `0x04`：当前时钟来源是 HSE
- `0x08`：当前时钟来源是 PLL

## 四、时钟树配置代码编写

### 4.1 配置目标

将时钟树从**初始状态**（8MHz）配置为**高性能状态**（72MHz）：

| 时钟 | 初始状态 | 目标状态 | 配置方法 |
|------|----------|----------|----------|
| SYSCLK | 8 MHz (HSI) | 72 MHz | HSE → PLL ×9 |
| HCLK | 8 MHz | 72 MHz | AHB 分频 = /1 |
| PCLK2 | 8 MHz | 72 MHz | APB2 分频 = /1 |
| PCLK1 | 8 MHz | 36 MHz | APB1 分频 = /2 |

### 4.2 配置步骤

配置时钟树需要按照以下**四步顺序**进行：

```
步骤 1：开启 HSE（外部高速时钟）
    │
    ▼
步骤 2：配置并启动 PLL（锁相环）
    │
    ▼
步骤 3：配置总线分频器（AHB、APB1、APB2）
    │
    ▼
步骤 4：切换系统时钟到 PLL
```

### 4.3 完整配置代码

```c
#include "stm32f10x.h"

/**
 * @brief 系统时钟初始化
 * @note  配置时钟树：HSE 8MHz → PLL ×9 → SYSCLK 72MHz
 */
void SystemClock_Init(void)
{
    // 步骤 1：开启 HSE（外部高速时钟）
    RCC_HSEConfig(RCC_HSE_ON);
    
    // 等待 HSE 就绪
    while (RCC_GetFlagStatus(RCC_FLAG_HSERDY) == RESET);
    
    
    // 步骤 2：配置并启动 PLL（锁相环）
    // PLL 输入：HSE（不分频）
    // PLL 倍频：×9
    // 输出：8MHz × 9 = 72MHz
    RCC_PLLConfig(RCC_PLLSource_HSE_Div1, RCC_PLLMul_9);
    
    // 启动 PLL
    RCC_PLLCmd(ENABLE);
    
    // 等待 PLL 就绪
    while (RCC_GetFlagStatus(RCC_FLAG_PLLRDY) == RESET);
    
    
    // 步骤 3：配置总线分频器
    // HCLK = SYSCLK / 1 = 72MHz
    RCC_HCLKConfig(RCC_SYSCLK_Div1);
    
    // PCLK1 = HCLK / 2 = 36MHz（APB1 不能超过 36MHz！）
    RCC_PCLK1Config(RCC_HCLK_Div2);
    
    // PCLK2 = HCLK / 1 = 72MHz
    RCC_PCLK2Config(RCC_HCLK_Div1);
    
    
    // 步骤 4：切换系统时钟到 PLL
    RCC_SYSCLKConfig(RCC_SYSCLKSource_PLLCLK);
    
    // 等待系统时钟切换完成
    while (RCC_GetSYSCLKSource() != 0x08);
}

int main(void)
{
    // 初始化系统时钟（72MHz）
    SystemClock_Init();
    
    // 用户代码...
    
    while (1);
}
```

## 五、Flash 指令预取和访问延迟配置

### 5.1 为什么需要配置 Flash？

**问题：** Flash 的读取速度跟不上 CPU 的执行速度

- CPU 时钟（SYSCLK）最高可达 72MHz
- Flash 接口的操作速度不能超过 24MHz
- 当 SYSCLK > 24MHz 时，Flash 需要插入等待周期

### 5.2 指令预取（Prefetch Buffer）

**概念**：在 CPU 执行当前指令时，Flash 提前将下一条指令放入缓冲区

```
┌─────────────────────────────────────────────────────────────┐
│                    指令预取机制                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   普通模式（无预取）           预取模式                      │
│                                                             │
│   CPU ──→ Flash ──→ 执行    CPU ──→ 预取缓冲区 ──→ 执行    │
│     ↑                             ↑                         │
│     └──────── 等待 ──────────────┘ Flash 提前填充            │
│                                                             │
│   缺点：Flash 慢，CPU 等待      优点：CPU 直接从缓冲区读取   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**开启指令预取：**

```c
// 开启 Flash 指令预取缓冲区
FLASH_PrefetchBufferCmd(FLASH_PrefetchBuffer_Enable);
```

**注意**：只能在 SYSCLK ≤ 8MHz 时调用此函数！

### 5.3 Flash 访问延迟（Latency）

根据 SYSCLK 频率设置 Flash 等待周期：

| SYSCLK 频率范围 | Flash 等待周期 | 配置参数 |
|-----------------|----------------|----------|
| 0 ~ 24 MHz | 0 个等待周期 | `FLASH_Latency_0` |
| 24 ~ 48 MHz | 1 个等待周期 | `FLASH_Latency_1` |
| 48 ~ 72 MHz | 2 个等待周期 | `FLASH_Latency_2` |

**设置 Flash 延迟：**

```c
// 设置 Flash 访问延迟为 2 个周期（当 SYSCLK = 72MHz 时）
FLASH_SetLatency(FLASH_Latency_2);
```

### 5.4 完整 Flash 配置代码

```c
void SystemClock_Init(void)
{
    // 步骤 0：配置 Flash（必须在 8MHz 下配置）
    // 开启指令预取
    FLASH_PrefetchBufferCmd(FLASH_PrefetchBuffer_Enable);
    
    // 设置 Flash 延迟（为 72MHz 准备）
    FLASH_SetLatency(FLASH_Latency_2);
    
    
    // 步骤 1：开启 HSE
    RCC_HSEConfig(RCC_HSE_ON);
    while (RCC_GetFlagStatus(RCC_FLAG_HSERDY) == RESET);
    
    
    // 步骤 2：配置并启动 PLL
    RCC_PLLConfig(RCC_PLLSource_HSE_Div1, RCC_PLLMul_9);
    RCC_PLLCmd(ENABLE);
    while (RCC_GetFlagStatus(RCC_FLAG_PLLRDY) == RESET);
    
    
    // 步骤 3：配置分频器
    RCC_HCLKConfig(RCC_SYSCLK_Div1);
    RCC_PCLK1Config(RCC_HCLK_Div2);
    RCC_PCLK2Config(RCC_HCLK_Div1);
    
    
    // 步骤 4：切换系统时钟
    RCC_SYSCLKConfig(RCC_SYSCLKSource_PLLCLK);
    while (RCC_GetSYSCLKSource() != 0x08);
}
```

## 六、片内外设时钟控制

### 6.1 外设时钟使能

STM32 的片内外设分布在三条总线上，分别使用不同的函数控制时钟：

| 总线 | 函数名 | 控制的外设 |
|------|--------|-----------|
| **AHB** | `RCC_AHBPeriphClockCmd()` | DMA1、DMA2、CRC、FSMC |
| **APB2** | `RCC_APB2PeriphClockCmd()` | GPIOA~G、USART1、SPI1、TIM1、ADC1~3 |
| **APB1** | `RCC_APB1PeriphClockCmd()` | USART2/3、I2C1/2、TIM2~7、SPI2/3、CAN、USB |

### 6.2 使能外设时钟示例

```c
// 开启 APB2 外设时钟（高速外设）
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);    // GPIOA
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);    // GPIOB
RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1, ENABLE);  // USART1
RCC_APB2PeriphClockCmd(RCC_APB2Periph_SPI1, ENABLE);    // SPI1
RCC_APB2PeriphClockCmd(RCC_APB2Periph_TIM1, ENABLE);    // TIM1
RCC_APB2PeriphClockCmd(RCC_APB2Periph_ADC1, ENABLE);    // ADC1

// 开启 APB1 外设时钟（低速外设）
RCC_APB1PeriphClockCmd(RCC_APB1Periph_USART2, ENABLE);  // USART2
RCC_APB1PeriphClockCmd(RCC_APB1Periph_USART3, ENABLE);  // USART3
RCC_APB1PeriphClockCmd(RCC_APB1Periph_I2C1, ENABLE);    // I2C1
RCC_APB1PeriphClockCmd(RCC_APB1Periph_I2C2, ENABLE);   // I2C2
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);    // TIM2

// 开启 AHB 外设时钟
RCC_AHBPeriphClockCmd(RCC_AHBPeriph_DMA1, ENABLE);      // DMA1
RCC_AHBPeriphClockCmd(RCC_AHBPeriph_DMA2, ENABLE);      // DMA2
```

### 6.3 外设复位

除了控制时钟，还可以对外设进行复位：

```c
// APB2 外设复位
RCC_APB2PeriphResetCmd(RCC_APB2Periph_GPIOA, ENABLE);   // 施加复位
RCC_APB2PeriphResetCmd(RCC_APB2Periph_GPIOA, DISABLE);   // 释放复位

// APB1 外设复位
RCC_APB1PeriphResetCmd(RCC_APB1Periph_I2C1, ENABLE);    // 施加复位
RCC_APB1PeriphResetCmd(RCC_APB1Periph_I2C1, DISABLE);   // 释放复位
```

**复位的作用：**
- 将外设寄存器恢复到初始状态
- 常用于外设出现异常时恢复

## 附录：完整时钟树配置代码

```c
/**
 * @file    system_clock.c
 * @brief   STM32F103 系统时钟配置
 * @details 配置时钟树为 72MHz（HSE 8MHz → PLL ×9）
 */

#include "stm32f10x.h"

/**
 * @brief 系统时钟初始化
 * @note  配置流程：
 *        1. 配置 Flash 预取和延迟
 *        2. 开启 HSE 并等待就绪
 *        3. 配置 PLL（HSE ×9）并启动
 *        4. 配置总线分频器
 *        5. 切换系统时钟到 PLL
 */
void SystemClock_Init(void)
{
    /* 步骤 0：配置 Flash（必须在 8MHz 下完成） */
    FLASH_PrefetchBufferCmd(FLASH_PrefetchBuffer_Enable);
    FLASH_SetLatency(FLASH_Latency_2);
    
    /* 步骤 1：开启 HSE（外部高速时钟 8MHz） */
    RCC_HSEConfig(RCC_HSE_ON);
    
    /* 等待 HSE 就绪 */
    while (RCC_GetFlagStatus(RCC_FLAG_HSERDY) == RESET);
    
    /* 步骤 2：配置 PLL */
    // PLL 输入：HSE（不分频）
    // PLL 倍频：×9
    // 输出：8MHz × 9 = 72MHz
    RCC_PLLConfig(RCC_PLLSource_HSE_Div1, RCC_PLLMul_9);
    
    /* 启动 PLL */
    RCC_PLLCmd(ENABLE);
    
    /* 等待 PLL 就绪 */
    while (RCC_GetFlagStatus(RCC_FLAG_PLLRDY) == RESET);
    
    /* 步骤 3：配置总线分频器 */
    // HCLK = SYSCLK / 1 = 72MHz
    RCC_HCLKConfig(RCC_SYSCLK_Div1);
    
    // PCLK1 = HCLK / 2 = 36MHz（APB1 不能超过 36MHz）
    RCC_PCLK1Config(RCC_HCLK_Div2);
    
    // PCLK2 = HCLK / 1 = 72MHz
    RCC_PCLK2Config(RCC_HCLK_Div1);
    
    /* 步骤 4：切换系统时钟到 PLL */
    RCC_SYSCLKConfig(RCC_SYSCLKSource_PLLCLK);
    
    /* 等待系统时钟切换完成 */
    while (RCC_GetSYSCLKSource() != 0x08);
}

/**
 * @brief 获取当前系统时钟频率
 * @return 系统时钟频率（Hz）
 */
uint32_t GetSystemClockFreq(void)
{
    // 简化版本：假设已配置为 72MHz
    // 完整版本应根据 RCC_CFGR 寄存器计算
    return 72000000;
}

/**
 * @brief 获取当前 HCLK 频率
 * @return HCLK 频率（Hz）
 */
uint32_t GetHCLKFreq(void)
{
    return 72000000;  // HCLK = SYSCLK = 72MHz
}

/**
 * @brief 获取当前 PCLK1 频率
 * @return PCLK1 频率（Hz）
 */
uint32_t GetPCLK1Freq(void)
{
    return 36000000;  // PCLK1 = HCLK / 2 = 36MHz
}

/**
 * @brief 获取当前 PCLK2 频率
 * @return PCLK2 频率（Hz）
 */
uint32_t GetPCLK2Freq(void)
{
    return 72000000;  // PCLK2 = HCLK = 72MHz
}
```

## 总结

**时钟树配置核心要点：**

1. **初始状态**：SYSCLK = HCLK = PCLK1 = PCLK2 = 8MHz（来自 HSI）

2. **标准库自动配置**：`SystemInit()` 会自动配置为 72MHz

3. **手动配置四步法**：
   - 开启 HSE
   - 配置并启动 PLL（HSE ×9）
   - 配置分频器（APB1 必须 /2）
   - 切换系统时钟到 PLL

4. **Flash 配置**：开启指令预取，设置访问延迟（72MHz 时需要 2 个等待周期）

5. **外设时钟**：根据外设所在总线（AHB/APB1/APB2）选择对应的时钟使能函数

**记忆口诀：**
```
时钟配置四步走，HSE、PLL、分频、切
Flash 预取要先开，延迟根据频率设
APB1 别超三十六，外设时钟按需开
```
