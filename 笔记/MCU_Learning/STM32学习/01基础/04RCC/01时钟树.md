## 一、时钟的基本概念

### 1.1 什么是时钟？

**时钟（Clock）** 是单片机内部的一种**高低电平交替变化的方波信号**，它就像人的心跳一样，为单片机的各个模块提供工作节拍。

```
     ┌───┐   ┌───┐   ┌───┐   ┌───┐
     │   │   │   │   │   │   │   │
─────┘   └───┘   └───┘   └───┘   └────
     ↑   ↑   ↑   ↑   ↑   ↑   ↑   ↑
    每个上升沿触发一次操作
```

### 1.2 时钟的作用

- **驱动外设工作**：所有片内外设（GPIO、UART、SPI、TIM 等）都需要时钟信号才能运行
- **控制工作速度**：时钟频率越高，外设工作速度越快
- **功耗管理**：关闭不需要的外设时钟可以降低功耗

### 1.3 之前接触过的时钟

#### 示例 1：开启 GPIO 时钟

```c
// 在使用 GPIOC 之前，必须先开启时钟
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);
```

只有开启时钟后，GPIOC 才能被操作。

#### 示例 2：UART 波特率产生

```
┌─────────┐    ┌─────────┐    ┌─────────┐
│ 时钟源  │───→│ 分频器1 │───→│ 分频器2 │───→ 波特率
│ 72MHz   │    │ 分频    │    │ 再/16   │
└─────────┘    └─────────┘    └─────────┘
```

UART 的波特率是通过时钟信号经过两级分频产生的。本章将解释这个 **72MHz** 时钟是如何来的。

## 二、时钟树概述

### 2.1 时钟树的比喻

单片机的时钟系统可以类比为**人体的血液循环系统**：

| 时钟系统         | 血液循环系统 | 功能                          |
| ---------------- | ------------ | ----------------------------- |
| **时钟源** | 心脏         | 产生时钟信号                  |
| **树干**   | 主动脉       | 时钟信号主干                  |
| **树枝**   | 血管分支     | 时钟分配                      |
| **树叶**   | 身体器官     | 片内外设（GPIO、SPI、UART等） |

### 2.2 STM32 的两棵时钟树

STM32 有两套独立的时钟系统：

```
┌─────────────────────────────────────────────┐
│              STM32 时钟系统                  │
├─────────────────────────────────────────────┤
│                                             │
│   ┌─────────────────────┐                   │
│   │   大树（高速时钟树）  │  ← 几十 MHz      │
│   │   High Speed Clock   │                  │
│   │                      │                  │
│   │   HSI (8MHz)         │                  │
│   │   HSE (4~16MHz)      │                  │
│   │   PLL → SYSCLK (72M)│                  │
│   │                      │                  │
│   │   → AHB/APB1/APB2   │                  │
│   │   → GPIO/UART/SPI   │                  │
│   └─────────────────────┘                   │
│                                             │
│   ┌─────────────────────┐                   │
│   │   小树（低速时钟树）  │  ← 几十 kHz      │
│   │   Low Speed Clock    │                  │
│   │                      │                  │
│   │   LSI (~40kHz)       │                  │
│   │   LSE (32.768kHz)    │                  │
│   │                      │                  │
│   │   → RTC（实时时钟）  │                  │
│   │   → IWDG（独立看门狗）│                 │
│   └─────────────────────┘                   │
│                                             │
└─────────────────────────────────────────────┘
```

## 三、时钟树的零部件

时钟树由三种基本零部件组成：

### 3.1 分频器（Divider）

**作用**：对输入时钟频率做**除法**（降低频率）

```
         分频器 (/N)
    ┌───────────────────┐
    │                   │
   F_in ──→ [÷N] ──→ F_out = F_in / N
    │                   │
    └───────────────────┘
```

**类型**：

- **固定分频器**：分频系数固定（如 `/2`）
- **可选分频器**：分频系数可配置（如 `/1`, `/2`, `/4`, `/8`...）

**例子**：

- HSI (8MHz) → `/2` 分频器 → 4MHz
- 72MHz → AHB 分频器 `/1` → 72MHz
- 72MHz → AHB 分频器 `/2` → 36MHz

### 3.2 锁相环（PLL - Phase Locked Loop）

**作用**：对输入时钟频率做**乘法**（倍频，提高频率）

```
         锁相环 (PLL)
    ┌───────────────────┐
    │                   │
   F_in ──→ [×N] ──→ F_out = F_in × N
    │                   │
    └───────────────────┘
```

**倍频系数**：可选 `×2` ~ `×16`

**例子**：

- HSE (8MHz) → PLL `×9` → 72MHz（系统最高频率）
- HSI/2 (4MHz) → PLL `×2` → 8MHz

### 3.3 复用器（MUX - Multiplexer）

**作用**：从**多路输入中选择一路**作为输出

```
         复用器 (MUX)
    ┌───────────────────┐
    │                   │
  输入1 ──→            │
  输入2 ──→ [选择器] ──→ 输出（选中的那路）
  输入3 ──→            │
    │                   │
    └───────────────────┘
```

**在时钟树中的表示**：梯形结构

**例子**：PLL 输入复用器可选择：

- HSI / 2
- HSE / 2
- HSE（直接）

## 四、树根：时钟源

STM32 共有 **4 个时钟源**，分为高速和低速两组：

### 4.1 时钟源概览

| 名称          | 全称                | 位置     | 频率       | 精度           | 用途       |
| ------------- | ------------------- | -------- | ---------- | -------------- | ---------- |
| **HSI** | High Speed Internal | 芯片内部 | 8 MHz      | 低（RC振荡器） | 高速时钟树 |
| **HSE** | High Speed External | 外部晶振 | 4~16 MHz   | 高（石英晶振） | 高速时钟树 |
| **LSI** | Low Speed Internal  | 芯片内部 | ~40 kHz    | 低             | 低速时钟树 |
| **LSE** | Low Speed External  | 外部晶振 | 32.768 kHz | 高             | 低速时钟树 |

### 4.2 命名规则

```
┌─────────────────────────────────────────────┐
│              时钟源命名规则                  │
├─────────────────────────────────────────────┤
│                                             │
│   第一个字母：速度等级                        │
│   ├── H = High（高速）→ 几十 MHz            │
│   └── L = Low（低速） → 几十 kHz            │
│                                             │
│   第二个字母：位置                            │
│   ├── S = Source / Internal（内部）         │
│   └── E = External（外部）                   │
│                                             │
│   组合含义：                                 │
│   ├── HSI = High Speed Internal（高速内部） │
│   ├── HSE = High Speed External（高速外部） │
│   ├── LSI = Low Speed Internal（低速内部）  │
│   └── LSE = Low Speed External（低速外部）  │
│                                             │
└─────────────────────────────────────────────┘
```

### 4.3 内部时钟 vs 外部时钟

#### 内部时钟源（HSI、LSI）

**优点**：

- 无需外部元件，使用方便
- 上电即用，启动快

**缺点**：

- 精度较低（RC 振荡器受温度影响）
- 频率固定不可调

#### 外部时钟源（HSE、LSE）

**优点**：

- 精度高（石英晶振稳定）
- 频率可在范围内选择

**缺点**：

- 需要外接晶振和负载电容
- 成本略高

### 4.4 实际硬件连接

在最小系统板上可以看到两颗晶振：

```
        ┌─────────────┐
        │   最小系统板  │
        │             │
        │  ┌───────┐  │
        │  │8.000  │  │  ← HSE（高速外部晶振）
        │  │银色   │  │    频率：8MHz
        │  └───────┘  │    引脚：PD0, PD1
        │             │
        │  ┌───────┐  │
        │  │32.768K│  │  ← LSE（低速外部晶振）
        │  │黑色   │  │    频率：32.768kHz
        │  └───────┘  │    引脚：PC14, PC15
        │             │
        └─────────────┘
```

### 4.5 为什么需要外部时钟？

虽然内部已有 HSI 和 LSI，但在以下情况需要外部晶振：

1. **需要高精度时钟**：如 UART 通信、USB 通信
2. **需要精确计时**：如 RTC 实时时钟（必须用 32.768kHz 晶振）
3. **需要超过 8MHz 的频率**：HSI 只有 8MHz，而 HSE 可达 16MHz，结合 PLL 可达 72MHz

## 五、树干：系统时钟的产生

### 5.1 系统时钟（SYSCLK）

**系统时钟**是 STM32 的主时钟，整个单片机的大部分外设都基于这个时钟工作。

**SYSCLK 有三种来源**：

```
┌─────────────────────────────────────────────┐
│           系统时钟（SYSCLK）来源             │
├─────────────────────────────────────────────┤
│                                             │
│   来源 1: HSI（8MHz）                        │
│   ┌─────┐                                   │
│   │ HSI │──────→ SYSCLK = 8MHz              │
│   │ 8MHz│       （简单，但精度低）           │
│   └─────┘                                   │
│                                             │
│   来源 2: HSE（4~16MHz）                     │
│   ┌─────┐                                   │
│   │ HSE │──────→ SYSCLK = HSE频率            │
│   │外接 │       （精度高，但频率受限）        │
│   └─────┘                                   │
│                                             │
│   来源 3: PLL 倍频输出（推荐）                │
│   ┌─────┐    ┌─────┐    ┌─────┐             │
│   │HSI  │───→│ /2  │───→│ PLL │───→ SYSCLK  │
│   │或HSE│    │可选 │    │×N   │    (灵活)   │
│   └─────┘    └─────┘    └─────┘             │
│                                             │
└─────────────────────────────────────────────┘
```

### 5.2 三种来源对比

| 来源     | 频率     | 精度           | 灵活性 | 适用场景                       |
| -------- | -------- | -------------- | ------ | ------------------------------ |
| HSI 直接 | 8MHz     | 低             | 差     | 对精度要求不高的简单应用       |
| HSE 直接 | 晶振频率 | 高             | 差     | 需要高精度但不需要高速         |
| PLL      | 可调     | 高（若用 HSE） | 好     | **推荐**，可灵活配置频率 |

### 5.3 PLL 配置详解

#### PLL 的输入选择（通过复用器）

```
                    ┌─────────────────┐
    HSI (8MHz) ──→  │                 │
            │      │   复用器 (MUX)   │
            └──→ /2 │                 │
                   │    ┌─────┐      │
    HSE (8MHz) ──→  │───→│ PLL │───→ SYSCLK
            │      │    │ ×N  │      │
            ├──→ /2 │    └─────┘      │
            │      │                 │
            └──→   │                 │
                   └─────────────────┘

    输入选项：
    - HSI / 2 = 4MHz
    - HSE / 2 = 4MHz（假设 HSE=8MHz）
    - HSE = 8MHz
```

#### 常用 PLL 配置方案

假设 HSE = 8MHz：

| 目标 SYSCLK      | PLL 输入 | 分频 | 倍频 | 计算                 |
| ---------------- | -------- | ---- | ---- | -------------------- |
| 8 MHz            | HSI      | /2   | ×2  | 8M/2×2 = 8M         |
| 12 MHz           | HSE      | /2   | ×3  | 8M/2×3 = 12M        |
| 16 MHz           | HSE      | /2   | ×4  | 8M/2×4 = 16M        |
| 24 MHz           | HSE      | /2   | ×6  | 8M/2×6 = 24M        |
| 32 MHz           | HSE      | /2   | ×8  | 8M/2×8 = 32M        |
| **72 MHz** | HSE      | /1   | ×9  | 8M×9 =**72M** |

#### 推荐配置（72MHz）

```
┌─────────────────────────────────────────────┐
│          推荐：72MHz 系统时钟配置             │
├─────────────────────────────────────────────┤
│                                             │
│   外部晶振：8MHz（HSE）                       │
│       │                                     │
│       │（不分频，直接输入）                    │
│       ↓                                     │
│   ┌─────┐                                   │
│   │ PLL │ 倍频系数 = ×9                      │
│   │ 8MHz│────────→ 72MHz                    │
│   └─────┘                                   │
│       │                                     │
│       ↓                                     │
│   SYSCLK = 72MHz（系统最高频率）              │
│                                             │
│   优势：                                    │
│   - 使用外部晶振，精度高                      │
│   - 达到系统最高频率，性能最强                │
│   - 满足大部分外设的时钟需求                  │
│                                             │
└─────────────────────────────────────────────┘
```

## 六、树枝：总线时钟分配

### 6.1 STM32 总线结构

STM32 内部有三条主要总线：

```
┌─────────────────────────────────────────────┐
│              STM32 总线结构                   │
├─────────────────────────────────────────────┤
│                                             │
│   ┌─────────────────────────────────────┐   │
│   │           Cortex-M3 内核             │   │
│   │         （系统时钟 = SYSCLK）         │   │
│   └─────────────┬───────────────────────┘   │
│                 │                           │
│   ┌─────────────▼───────────────────────┐   │
│   │            AHB 总线                 │   │
│   │     （Advanced High-speed Bus）      │   │
│   │         HCLK = SYSCLK / AHB_DIV      │   │
│   │                                     │   │
│   │   ┌─────────┐   ┌─────────┐        │   │
│   │   │  DMA1   │   │  DMA2   │        │   │
│   │   └─────────┘   └─────────┘        │   │
│   └──────────┬──────────────────────────┘   │
│              │                              │
│    ┌─────────┴──────────┐                   │
│    │                      │                  │
│    ↓                      ↓                  │
│ ┌─────────────┐      ┌─────────────┐        │
│ │  APB2 总线   │      │  APB1 总线   │        │
│ │（高速外设）  │      │（低速外设）  │        │
│ │ PCLK2 =    │      │ PCLK1 =      │        │
│ │ HCLK/APB2_DIV│     │ HCLK/APB1_DIV│        │
│ │             │      │              │        │
│ │ GPIOA~E    │      │ USART2/3     │        │
│ │ SPI1       │      │ I2C1/2       │        │
│ │ USART1     │      │ TIM2~7       │        │
│ │ TIM1       │      │              │        │
│ │ ADC1~3     │      │              │        │
│ └─────────────┘      └─────────────┘        │
│                                             │
└─────────────────────────────────────────────┘
```

### 6.2 总线与外设对应关系

#### APB2 总线外设（高速）

| 外设    | 时钟源 | 最高频率 |
| ------- | ------ | -------- |
| GPIOA~G | PCLK2  | 72 MHz   |
| SPI1    | PCLK2  | 72 MHz   |
| USART1  | PCLK2  | 72 MHz   |
| TIM1    | PCLK2  | 72 MHz   |
| ADC1~3  | PCLK2  | 72 MHz   |

#### APB1 总线外设（低速）

| 外设           | 时钟源 | 最高频率 |
| -------------- | ------ | -------- |
| USART2、USART3 | PCLK1  | 36 MHz   |
| I2C1、I2C2     | PCLK1  | 36 MHz   |
| TIM2~TIM7      | PCLK1  | 36 MHz   |
| SPI2、SPI3     | PCLK1  | 36 MHz   |
| CAN、USB       | PCLK1  | 36 MHz   |

```
│       │                                     │
│       │（树干）                              │

│    │               │                        │
│    ↓               ↓                        │
```

### 6.4 分频器配置规则

#### AHB 分频器（HCLK）

```c
// RCC_CFGR 寄存器的 HPRE 位
// 分频系数可选：/1, /2, /4, /8, /16, /64, /128, /256, /512

SYSCLK = 72MHz 时：
- /1  → HCLK = 72MHz
- /2  → HCLK = 36MHz
- /4  → HCLK = 18MHz
```

#### APB2 分频器（PCLK2）

```c
// RCC_CFGR 寄存器的 PPRE2 位
// 分频系数可选：/1, /2, /4, /8, /16

HCLK = 72MHz 时：
- /1  → PCLK2 = 72MHz（最大值）
- /2  → PCLK2 = 36MHz
```

#### APB1 分频器（PCLK1）

```c
// RCC_CFGR 寄存器的 PPRE1 位
// 分频系数可选：/1, /2, /4, /8, /16

// 注意：APB1 最高频率限制为 36MHz！

HCLK = 72MHz 时：
- /1  → PCLK1 = 72MHz（超过限制，不可行！）
- /2  → PCLK1 = 36MHz（最大值，推荐）
- /4  → PCLK1 = 18MHz
```

### 6.5 编程对应关系

```c
// 开启 APB2 外设时钟（高速外设）
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);   // GPIOA
RCC_APB2PeriphClockCmd(RCC_APB2Periph_SPI1, ENABLE);     // SPI1
RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1, ENABLE);   // USART1
RCC_APB2PeriphClockCmd(RCC_APB2Periph_TIM1, ENABLE);     // TIM1
RCC_APB2PeriphClockCmd(RCC_APB2Periph_ADC1, ENABLE);     // ADC1

// 开启 APB1 外设时钟（低速外设）
RCC_APB1PeriphClockCmd(RCC_APB1Periph_USART2, ENABLE);   // USART2
RCC_APB1PeriphClockCmd(RCC_APB1Periph_USART3, ENABLE);   // USART3
RCC_APB1PeriphClockCmd(RCC_APB1Periph_I2C1, ENABLE);       // I2C1
RCC_APB1PeriphClockCmd(RCC_APB1Periph_I2C2, ENABLE);     // I2C2
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);     // TIM2
```

## 七、时钟配置实例

### 7.1 实例 1：全速配置（72MHz）

**目标**：系统时钟达到最高频率 72MHz，且所有总线时钟都达到最大值。

**硬件前提**：外接 8MHz 晶振（HSE）

**配置步骤**：

```c
// 1. 使能 HSE（外部高速时钟）
RCC_HSEConfig(RCC_HSE_ON);
while (RCC_GetFlagStatus(RCC_FLAG_HSERDY) == RESET);  // 等待 HSE 就绪

// 2. 配置 PLL
//    输入：HSE = 8MHz
//    不分频，直接输入 PLL
//    PLL 倍频系数 = 9
//    输出：8MHz × 9 = 72MHz
RCC_PLLConfig(RCC_PLLSource_HSE_Div1, RCC_PLLMul_9);

// 3. 使能 PLL
RCC_PLLCmd(ENABLE);
while (RCC_GetFlagStatus(RCC_FLAG_PLLRDY) == RESET);  // 等待 PLL 就绪

// 4. 配置总线分频器
//    SYSCLK = 72MHz
//    HCLK = SYSCLK / 1 = 72MHz  (AHB 分频 = /1)
//    PCLK2 = HCLK / 1 = 72MHz   (APB2 分频 = /1)
//    PCLK1 = HCLK / 2 = 36MHz   (APB1 分频 = /2，不能超过36MHz)
RCC_HCLKConfig(RCC_SYSCLK_Div1);   // AHB 分频 = /1
RCC_PCLK2Config(RCC_HCLK_Div1);    // APB2 分频 = /1
RCC_PCLK1Config(RCC_HCLK_Div2);    // APB1 分频 = /2

// 5. 切换系统时钟到 PLL
RCC_SYSCLKConfig(RCC_SYSCLKSource_PLLCLK);
while (RCC_GetSYSCLKSource() != 0x08);  // 等待切换完成

// 配置完成！
// SYSCLK = 72MHz, HCLK = 72MHz, PCLK2 = 72MHz, PCLK1 = 36MHz
```

### 7.2 实例 2：低速节能配置（8MHz）

**目标**：使用内部时钟，简化配置，降低功耗。

**配置步骤**：

```c
// 使用 HSI 直接作为系统时钟（无需配置 PLL）

// 1. 配置总线分频器
RCC_HCLKConfig(RCC_SYSCLK_Div1);   // AHB 分频 = /1
RCC_PCLK2Config(RCC_HCLK_Div1);    // APB2 分频 = /1
RCC_PCLK1Config(RCC_HCLK_Div1);    // APB1 分频 = /1

// 2. 切换系统时钟到 HSI（默认就是 HSI，但明确写出）
RCC_SYSCLKConfig(RCC_SYSCLKSource_HSI);

// 配置完成！
// SYSCLK = 8MHz, HCLK = 8MHz, PCLK2 = 8MHz, PCLK1 = 8MHz
```

### 7.3 实例 3：自定义频率（48MHz，用于 USB）

**目标**：产生 48MHz 系统时钟（USB 需要 48MHz）。

**硬件前提**：外接 8MHz 晶振

**配置计算**：

- HSE = 8MHz
- 需要 48MHz 输出
- 8MHz × 6 = 48MHz

**配置步骤**：

```c
// 1. 使能 HSE
RCC_HSEConfig(RCC_HSE_ON);
while (RCC_GetFlagStatus(RCC_FLAG_HSERDY) == RESET);

// 2. 配置 PLL：8MHz × 6 = 48MHz
RCC_PLLConfig(RCC_PLLSource_HSE_Div1, RCC_PLLMul_6);

// 3. 使能 PLL
RCC_PLLCmd(ENABLE);
while (RCC_GetFlagStatus(RCC_FLAG_PLLRDY) == RESET);

// 4. 配置总线分频器
RCC_HCLKConfig(RCC_SYSCLK_Div1);   // HCLK = 48MHz
RCC_PCLK2Config(RCC_HCLK_Div1);    // PCLK2 = 48MHz
RCC_PCLK1Config(RCC_HCLK_Div2);    // PCLK1 = 24MHz (最高36MHz，满足)

// 5. 切换系统时钟到 PLL
RCC_SYSCLKConfig(RCC_SYSCLKSource_PLLCLK);

// 配置完成！
// SYSCLK = 48MHz, HCLK = 48MHz, PCLK2 = 48MHz, PCLK1 = 24MHz
```

## 九、常见问题

### Q1: 为什么我的 UART 波特率不对？

**A**: 检查系统时钟配置。UART 波特率计算公式：

```
波特率 = PCLK / (16 × USARTDIV)
```

如果系统时钟不是预期的 72MHz，波特率就会偏差。

**解决方法**：

1. 确认 HSE 晶振频率（常见 8MHz 或 12MHz）
2. 确认 PLL 倍频系数
3. 重新计算 USARTDIV 值

### Q2: APB1 外设时钟配置为 72MHz 会怎样？

**A**: **不行！** APB1 最高只允许 36MHz。如果配置为 72MHz：

- 部分外设可能工作不正常
- 可能损坏某些外设

**正确配置**：当 HCLK = 72MHz 时，APB1 分频器必须配置为 `/2` 或更大。

### Q3: 内部时钟 HSI 和外部时钟 HSE 哪个更好？

**A**:

- **HSI**：方便，无需外接晶振，但精度差（±2%），适合简单应用
- **HSE**：需要外接晶振，但精度高（±30ppm），适合需要精确通信的应用（如 USB、UART、CAN）

### Q4: 如何查询当前系统时钟频率？

**A**: 可以通过 RCC_CFGR 寄存器的 SWS 位查询当前时钟源，但要知道具体频率需要：

1. 知道外部晶振频率
2. 查询 PLL 配置

### Q5: 时钟配置出错会怎样？

**A**:

- **配置过高**：超过芯片标称最大频率，可能不稳定或损坏
- **配置过低**：功能正常，但性能下降
- **PLL 配置错误**：系统可能死机或无法启动
- **时钟源切换错误**：可能导致系统时钟失效

### Q6: 使用标准库函数 `SystemInit()` 做了什么？

**A**: 启动文件中的 `SystemInit()` 函数通常：

1. 使能 HSE
2. 配置 PLL 为 72MHz（假设 HSE=8MHz）
3. 配置总线分频器
4. 切换系统时钟到 PLL

这是固件库默认配置，可以在 `system_stm32f10x.c` 中修改。

## 总结

**核心要点**：

1. STM32 有 4 个时钟源：HSI、HSE、LSI、LSE
2. 时钟树由分频器（除法）、锁相环（乘法）、复用器（选择）组成
3. 系统时钟 SYSCLK 可由 HSI、HSE 或 PLL 产生
4. 推荐配置：HSE 8MHz → PLL ×9 → 72MHz SYSCLK
5. APB1 最高 36MHz，APB2 最高 72MHz
6. 使用外设前必须先开启对应总线的时钟

**记忆口诀**：

```
HSI HSE 高速用，LSI LSE 低速行
内部方便精度低，外部精准要外接
PLL 倍频最灵活，8M 乘 9 得 72M
APB1 别超 36M，APB2 可到 72M
```
