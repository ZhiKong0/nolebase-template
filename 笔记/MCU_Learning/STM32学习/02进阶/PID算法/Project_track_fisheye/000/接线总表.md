# 三轮小车接线总表（12 路模板）

> 适用工程：[`Project_track_fisheye`](/F:/Documents/GitHub/nolebase-template/笔记/MCU_Learning/STM32学习/02进阶/PID算法/Project_track_fisheye)
>
> 当前代码侧循迹前端已经固定为：
> `4 路直连 + 74HC4051 扫描 8 路 = 12 路输入`
>
> 位序统一按物理从左到右：
> `bit0=A1, bit1=A2, bit2=A3, ... , bit9=A10, bit10=A11, bit11=A12`

## 1. 当前硬件口径

- 主控：`STM32F103C8T6`
- 电机驱动：`TB6612`
- 电机编码器：`MG310(GMR)`
- IMU 预留：`BNO085` 软件 I2C
- OLED：软件 I2C
- 主串口：`USART1` 重映射到 `PB6/PB7`
- 循迹输入：
  - 直连：`A1/A2/A11/A12`
  - 扫描：`74HC4051` 选择 `A3~A10`

## 5. 主串口（DAPlink 有线 / 无线透传）

> 当前主串口只有这一组：`USART1` 重映射到 `PB6/PB7`。
> 你板上的 DAPlink 无线串口能力，本质上也还是落在这同一组引脚。

| 功能 | STM32 引脚 | 对外连接 |
| --- | --- | --- |
| `USART1_TX` | `PB6` | 接 DAPlink `RXD` |
| `USART1_RX` | `PB7` | 接 DAPlink `TXD` |
| `GND` | `GND` | 共地 |

- 串口参数：`115200 8N1`
- 用途：
  - 命令下发
  - 遥测输出
  - DAPLink 有线串口
  - DAPLink 无线透传串口

## 8. 12 路循迹前端

### 8.1 结构说明

- `A1/A2/A11/A12`：4 路直连到 STM32
- `A3~A10`：8 路进 `74HC4051`
- `74HC4051` 的 `S0/S1/S2` 由 STM32 轮询切换
- `74HC4051` 的 `Z` 输出送回 STM32 读取
- MCU 在 `LineSensor_Read()` 内部把 12 路整理成一帧 `uint16_t bits`

### 8.2 74HC4051 ↔ STM32

| 74HC4051 引脚 | 连接到 | 说明 |
| --- | --- | --- |
| `VCC` | `3.3V` | 与 MCU 逻辑同电压 |
| `GND` | `GND` | 共地 |
| `VEE` | `GND` | 数字应用接地 |
| `E/INH` | `GND` | 低有效，固定使能 |
| `S0` | `PA2` | 选择位 0 |
| `S1` | `PA11` | 选择位 1 |
| `S2` | `PA10` | 选择位 2 |
| `Z` | `PA3` | 公共输出，STM32 输入 |
| `Y0` | 12 路模块 `A3` | 扫描第 1 路 |
| `Y1` | 12 路模块 `A4` | 扫描第 2 路 |
| `Y2` | 12 路模块 `A5` | 扫描第 3 路 |
| `Y3` | 12 路模块 `A6` | 扫描第 4 路 |

## 10. 上电前检查

| 检查项 | 标准 |
| --- | --- |
| 共地 | 电池、STM32、TB6612、编码器、OLED、BNO、74HC4051、12 路模块、DAPlink 必须全共地 |
| 逻辑电压 | `STM32 / OLED / BNO / 74HC4051 / 12 路输入` 统一按 `3.3V` 逻辑检查 |
| 4051 使能 | `E/INH` 必须拉低到 `GND` |
| 12 路位序 | 物理从左到右必须对应 `A1 ~ A12` |
| 主串口 | `PB6/PB7` 只留给 DAPlink 主串口，不要再复用成别的外设 |
| BNO085 模式脚 | 若后续启用 IMU，`PS0=0`、`PS1=1`、`ADDR` 不悬空 |
| 直连 + 扫描 | `A1/A2/A11/A12` 与 `A3~A10` 两部分都要分别检查导通 |
