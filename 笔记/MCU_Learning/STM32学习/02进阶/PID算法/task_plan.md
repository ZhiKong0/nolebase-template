解决 `Project_Refactor_track-421 - 副本 (2)` 在 `TRACK` 模式下“速度慢、左右晃、轮端一卡一卡”的问题，并验证弯道增强参数是否值得保留。

## 当前结论

- 当前慢速与顿挫的主根因是 `TRACK` 速度斜坡、轮端死区补偿、轮端限幅三层控制互相打架，而不是单纯 `KP/KD` 不够。
- 已把 `TRACK` 改回“快斜坡但不直通目标速度 + 双轮各自过死区 + 双轮斜率限制”，并在中心区限制差速预算，减少单轮反复掉进死区。
- 围绕弯道增强组 `35.64 / 0.04 / 0.62 / 0.68` 做了二分；`0.5 / 0.25 / 0.125` 三个中间点都不如默认组稳定，说明这条增强方向本身不该继续作为主线。
- 当前已换到更有效的新方向：
  - 启动见线宽限，避免一启动就 `TURN`
  - `scheduleAlpha` 平滑，减少动态 steering 瞬时跳变
  - `curve_load` 真源降敏，减少长时间卡在高 `ga`
  - `TTR` 一维搜索确定当前最稳点在 `4.0`
- 当前默认组已更新为包含 `TTR=4.0` 的版本；如果后续还要继续收，优先继续做 `TTR` 附近的细粒度搜索，再决定是否需要单独给直线段加轻微 `TCA0`。
- 本轮新增的关键变化是：`TRACK` 主控制量已切换为“中心优先离散误差”，当前主线不再是旧的连续加权位置均值。
- 这条新主线已经跑出过明显更好的结果，但重复性仍受起跑姿态影响；后续继续调时，应围绕“首段起跑一致性 + 中心优先误差细化”继续推进。
- 当前进一步收敛后的基线是：
  - 保留中心优先离散误差
  - 保留中心位时序钳制
  - 中心区直接按位型给小误差并弱化微分
  - 默认 `TTR` 回到 `2.0`
- 本轮新增验证结论：
  - “更硬的 `S4|S5` 中心直控 + 更快退回直线档”这条代码方向已证伪，不继续保留。
  - 恢复稳态主线后，当前最优运行时参数是 `smooth_damp`：
    - `kp_straight = 16.732`
    - `kd_straight = 11.88`
    - `deadband_straight = 0.27`
    - `center_anchor_straight = 0.26`
    - `steer_trim = 2.0`
  - 板端当前已恢复为这组运行时参数，没有保留本轮坏试验值。
