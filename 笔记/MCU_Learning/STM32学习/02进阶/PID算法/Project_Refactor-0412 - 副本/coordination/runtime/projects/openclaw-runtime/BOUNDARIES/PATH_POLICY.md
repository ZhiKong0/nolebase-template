# Path Policy

## Zone Rules

| Zone | Rule | Notes |
| --- | --- | --- |
| `README_INDEX.md`, `ARCHITECTURE_INDEX.md`, `ARCHITECTURE_TREE.json` | read-only for task AIs | regenerated by scripts or maintainer AI |
| `CHANGELOG_TIER/L0_BASE/` | read-only after init | only rebuilt during baseline reset |
| `STREAM_LOG/STREAM.jsonl` | append-only through triad commands only | live source of truth for active runtime |
| `STREAM_LOG/NEWEST_ENTRY.json`, `STREAM_LOG/LATEST_TAIL.json`, `STREAM_LOG/SESSION_HEADS.json` | script-managed atomic summaries | never hand-edit; regenerated from `STREAM.jsonl` |
| `STREAM_LOG/READ_POINTERS/` | writable by the reading agent and scripts | per-agent per-mode consumption state |
| `CHANGELOG_TIER/L1_ACTIVE/` | script and active session managed | do not edit another session entry directly |
| `CHANGELOG_TIER/L2_RECENT/` | read-mostly | updated by release/archive flow |
| `CHANGELOG_TIER/L3_DIGEST/` | append-only for new digest nodes | never overwrite existing digest files |
| `CHANGELOG_TIER/L4_ARCHIVE/` | read-only | audit only |
| `LOGS/operations/` | append-only | one JSON object per line |
| `LOGS/conflicts/` | append-only | conflict evidence only |
| `state/events/STATE_EVENTS.jsonl` | append-only | state transition ledger |
| `state/transactions/active/`, `state/transactions/history/` | script-managed | transaction metadata only |
| `state/internal_locks/` | script-managed | internal coordination locks only |
| `SESSIONS/active/<session-id>/` | writable only by owning session | contains `SESSION_DELTA.json`, `THOUGHT.jsonl`, `EXEC.jsonl`, `MOD.jsonl` |
| `SESSIONS/archive/` | read-only after archive | closed sessions only |
| `context/LIVE_STATE_BOARD.md` | script-managed | lightweight whole-room view only |
| `context/BOARD.md` | shared write with short updates only | high-signal status only |
| `context/HANDOFF.md` | shared write on baton handoff | rewrite the top snapshot |
| `context/DECISIONS.md` | append-only rows | durable decisions only |
| `tasks/TASK-xxx.md` | writable by owning task session | keep metadata and status current |
| `locks/TASK-xxx.json` | writable by owning task session and scripts | scope contract |
| `STAGING/patches/` | writable by non-owner sessions | submit diff/patch here instead of direct edit |

## Direct Edit Block

If a target path is covered by another active lock:

1. do not edit it directly
2. write a patch proposal under `STAGING/patches/`
3. record a conflict or proposal log entry
4. append a human-readable note to `LOGS/CONFLICT_LOG.md`
5. wait for the owner session or operator to resolve it

## Metadata Header Rule

All AI-maintained Markdown files must preserve the YAML metadata header at the top of the file.

Do not remove or reorder metadata keys unless the file template changes.

## Lossy Boundary Rule

- `NEWEST_ENTRY.json` and `LATEST_TAIL.json` are summaries, not authoritative history.
- When `coord-read-stream` reports a missing pointer target, stop and reload `LIVE_STATE_BOARD.md`, `SESSION_HEADS.json`, and `L3_DIGEST/latest_summary.md` first.
- Only use `-AcceptLossyBoundary` when you intentionally accept resuming from the current stream head.
