# 三轮小车接线总表（STM32F103C8T6 + TB6612 + MG310(GMR) + ICM42688 / BNO085 + OLED）

> 本表按当前工程代码与接线方案整理：默认 IMU 为 `ICM42688`，使用 `PB12/PB13` 软件 I2C；若后续改用 `BNO085`，也建议优先复用这组 I2C 引脚。

## 1. 电源与地

| 模块端                 | 连接到                  | 说明                |
| ---------------------- | ----------------------- | ------------------- |
| 电池正极               | TB6612 `VM`           | 电机电源（如 7.4V） |
| 电池正极               | 3.3V稳压模块 `VIN+`   | 给逻辑电源降压      |
| 3.3V稳压模块 `VOUT+` | STM32 `3.3V`          | 主控供电            |
| 3.3V稳压模块 `VOUT+` | TB6612 `VCC`          | 驱动逻辑供电        |
| 电池负极               | STM32 `GND`           | 共地                |
| 电池负极               | TB6612 `GND`          | 共地                |
| 电池负极               | 编码器/MPU/OLED `GND` | 全系统共地          |

## 4. ICM42688（软件 I2C）

| ICM42688 引脚 | STM32 引脚     | 说明                                                 |
| ------------- | -------------- | ---------------------------------------------------- |
| `VCC`       | `3.3V`       | 模块供电（以模块规格为准，推荐 3.3V）                |
| `GND`       | `GND`        | 共地                                                 |
| `SCL/SCLK`  | `PB12`       | 软件 I2C SCL                                         |
| `SDA/MOSI`  | `PB13`       | 软件 I2C SDA                                         |
| `ADO/MISO`  | `GND`        | I2C 地址选择：接 GND ->`0x68`，接 3.3V -> `0x69` |
| `CS`        | （悬空或接高） | I2C 模式不用（SPI 模式低有效）                       |
| `INTT`      | （可不接）     | 中断输出1（可接 EXTI）                               |
| `INT2`      | （可不接）     | 中断输出2（可选）                                    |
| `3V3`       | NC             | 3.3V 稳压输出（可不接）                              |
| `NC`        | NC             | 悬空                                                 |

> 建议：`PB12/PB13` 各接一个 4.7k 上拉到 3.3V（若模块板载上拉，可先不外接）。

### 4.1 BNO085（推荐 I2C，作为 ICM42688 替换方案）

| BNO085 引脚 | STM32 引脚（推荐）       | 说明                                   |
| ----------- | ------------------------ | -------------------------------------- |
| `VDD`     | `3.3V`                 | 模块供电，严禁直接接 5V                |
| `GND`     | `GND`                  | 共地                                   |
| `SCL`     | `PB12`                 | 推荐复用当前 IMU 的 I2C 时钟脚         |
| `SDA`     | `PB13`                 | 推荐复用当前 IMU 的 I2C 数据脚         |
| `INT`     | `PA15` 或任意空闲 GPIO | 数据就绪中断，建议连接；若用 `PA15`，需释放 JTAG |
| `RST`     | `PB11` 或任意空闲 GPIO | 软件复位，建议接可控 GPIO              |
| `ADDR`    | `GND` 或 `3.3V`      | 地址选择：`GND -> 0x28`，`3.3V -> 0x29` |
| `PS0`     | `GND`                  | I2C 模式选择                           |
| `PS1`     | `3.3V`                 | I2C 模式选择                           |

> 推荐替换方式：直接把原 `ICM42688` 的 `PB12/PB13` 改接到 `BNO085` 的 `SCL/SDA`，这样改线最少。当前工程建议把 `RST` 放到 `PB11`，把 `PB14/PB15` 留给无线串口。

## 5. DAPlink 主串口

### 5.1 STM32 串口引脚

| 串口功能      | STM32 引脚 | 说明                    |
| ------------- | ---------- | ----------------------- |
| `USART1_TX` | `PB6`    | `USART1` 重映射发送脚 |
| `USART1_RX` | `PB7`    | `USART1` 重映射接收脚 |

### 5.2 DAPlink 串口接线

| DAPlink 引脚 | 连接到  | 说明                            |
| ------------ | ------- | ------------------------------- |
| `TXD`      | `PB7` | DAPlink 发到单片机，接 MCU `RX` |
| `RXD`      | `PB6` | 单片机发到 DAPlink，接 MCU `TX` |
| `GND`      | `GND` | 必须共地                        |

### 5.3 当前工程说明

- 串口参数统一按：`115200`、`8N1`、无校验。
- `PB6/PB7` 当前只承担 `DAPlink / 命令 / 遥测` 主串口。
- 当前工程里说的“循迹数据帧”，指的是：
  - `74HC4051` 逐路扫描 `A3~A10`
  - 在 MCU 内部整理成 `8` 位状态帧
  - 再由 `LineSensor_Read()` / `line_track` 消费
- 也就是说，当前现行方案的循迹输入前端仍然是 `74HC4051`，不是额外的外部 UART 循迹模块直连 `PB6/PB7`。

## 6. 无线串口（预留）

> 当前工程代码已把 `PB14/PB15` 从 IMU 复位脚里腾出来，作为无线串口预留位；本轮主要完成了引脚边界收口，未额外启用完整的软件串口业务链。

| 无线串口模块引脚 | 连接到  | 说明 |
| ---------------- | ------- | ---- |
| `TXD`          | `PB15` | 模块发到单片机，接 MCU `RX` |
| `RXD`          | `PB14` | 单片机发到模块，接 MCU `TX` |
| `GND`          | `GND`  | 必须共地 |
| `VCC`          | `3.3V` 或按模块规格 | 供电按模块规格确认 |

### 6.1 无线串口说明

- 这组引脚用于给后续蓝牙 / 433 / 透明传输串口模块预留第二条串口链。
- `PB14/PB15` 本身**不是** JTAG 脚，不需要因为这两个脚单独禁用 JTAG。
- 若 `BNO085_INT` 继续放在 `PA15`，则当前工程仍需释放 `PA15/PB3/PB4` 的 JTAG 复用；代码里已经在 `BNO085_Init()` 中执行 `GPIO_Remap_SWJ_JTAGDisable`。

## 9. 按键模块

| 按键     | STM32 引脚 | 功能                          |
| -------- | ---------- | ----------------------------- |
| `按键` | `PB5`    | 短按=启动/停止，长按=切换速度 |

**接线方式（上拉输入模式）：**

```
按键: 一端接PB5，另一端接GND

短按（<1秒）= 启动/停止电机
长按（≥1秒）= 切换速度档位

按下时 = 低电平（触发）
松开时 = 高电平（内部上拉）
```

## 10. 74HC4051 + 12 路循迹模块（当前工程现行方案）

> 当前 `Project_Refactor_track-421 - 副本 (3)` 的循迹前端仍然是 `74HC4051 + 12 路模块 A3~A10`。代码侧会把扫描结果整理成 MCU 内部 8 位状态帧，所以这里的“数据帧”不是指外部 UART 模块独立发串口帧。

| 74HC4051 模块丝印 | 芯片功能 | 接线目标 | 关键说明 |
| :--- | :--- | :--- | :--- |
| **VCC** | 正电源 | **3.3V** | 供电电压，与STM32逻辑电平一致 |
| **GND** | 电源地 | **STM32 GND** | **必须共地**！否则电平错乱无法工作 |
| **VEE** | 模拟负电源 | **GND** | 数字应用时接地 |
| **E** | 使能端（低有效） | **GND** | 接地=始终使能，省一个IO口 |
| **S0** | 地址位0 | **STM32 PA2** | 通道选择最低位 |
| **S1** | 地址位1 | **STM32 PA11** | 通道选择中间位 |
| **S2** | 地址位2 | **STM32 PA10** | 通道选择最高位 |
| **Z** | 公共输入/输出 | **STM32 PA3** | 上拉输入，读取选中通道的数据 |
| **Y0** | 通道0 | **12路循迹模块 - A3** | 第1路信号（最左） |
| **Y1** | 通道1 | **12路循迹模块 - A4** | 第2路信号（L1） |
| **Y2** | 通道2 | **12路循迹模块 - A5** | 第3路信号（L0） |
| **Y3** | 通道3 | **12路循迹模块 - A6** | 第4路信号 |
| **Y4** | 通道4 | **12路循迹模块 - A7** | 第5路信号 |
| **Y5** | 通道5 | **12路循迹模块 - A8** | 第6路信号（R0） |
| **Y6** | 通道6 | **12路循迹模块 - A9** | 第7路信号（R1） |
| **Y7** | 通道7 | **12路循迹模块 - A10** | 第8路信号（最右） |

### 10.1 工作原理

1. **选择通道**：通过S0~S2三位地址码选择Y0~Y7中的某一路
2. **读取数据**：被选中的通道与Z引脚导通，STM32读取PA3(Z)即可获得该路传感器状态
3. **循环扫描**：依次切换S0~S2选择8个通道，逐路读取，组合成8位传感器数据

### 10.2 12路循迹模块接线（实际使用 A3~A10 八路）

| 12路循迹模块引脚 | 连接到 | 说明 |
| ---------------- | ---------- | ---- |
| `VCC`          | `3.3V`     | 模块供电 |
| `GND`          | `GND`      | 必须共地 |
| `A3`           | `74HC4051 Y0` | 第1路信号（最左） |
| `A4`           | `74HC4051 Y1` | 第2路信号 |
| `A5`           | `74HC4051 Y2` | 第3路信号 |
| `A6`           | `74HC4051 Y3` | 第4路信号 |
| `A7`           | `74HC4051 Y4` | 第5路信号 |
| `A8`           | `74HC4051 Y5` | 第6路信号 |
| `A9`           | `74HC4051 Y6` | 第7路信号 |
| `A10`          | `74HC4051 Y7` | 第8路信号（最右） |
| `A0`~`A2`      | 不接        | 未使用 |
| `A11`          | 不接        | 未使用 |

## 11. 上电前检查

| 检查项    | 标准                                                                    |
| --------- | ----------------------------------------------------------------------- |
| 共地      | 电池负极、STM32 GND、TB6612 GND、编码器 GND、ICM/BNO GND、OLED GND、74HC4051 GND、12路循迹 GND、无线串口/DAPlink GND 全部连通 |
| 逻辑电压  | STM32/TB6612 VCC/编码器/ICM/BNO/OLED 都是 3.3V                              |
| STBY 逻辑 | `PB0=0` 电机不转，`PB0=1` 才允许驱动                                |
| BNO085 模式脚 | 若使用 BNO085 的 I2C，推荐 `PS0=0`、`PS1=1`，且 `ADDR` 不要悬空        |
| 主串口接线 | `PB6/PB7` 默认给 `DAPlink` / 命令串口使用 |
| 无线串口预留 | 若接无线串口，默认走 `PB14/PB15`；该组脚位与当前 `BNO085_RST` 不再冲突 |
| 74HC4051 现行 | 当前工程就是这套方案，需要检查 VCC/GND/VEE/E/S0/S1/S2/Z 与 A3~A10 接线 |
