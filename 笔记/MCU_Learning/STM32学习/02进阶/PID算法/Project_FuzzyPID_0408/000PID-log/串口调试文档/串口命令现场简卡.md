# 串口命令现场简卡

## 1. 串口固定配置

- **[端口]** `COM18`
- **[波特率]** `115200`
- **[格式]** `8N1`
- **[文本诊断前提]** 先发 `#VOFA=0!`

> **安全警告**
>
> `#RUN!`、`#EXP=RUN,...!`、`#RAW=...!` 前必须先架空小车。

---

## 2. 最常用 10 条命令

| 命令 | 用途 | 典型回包 |
| --- | --- | --- |
| `#VOFA=0!` | 切回文本模式 | `OK VOFA` |
| `#STOP!` | 停机 | `OK STOP` |
| `#STAT!` | 查看当前完整状态 | `STAT ...` |
| `#CAL!` | 锁定当前航向为参考 | `OK CAL` |
| `#IMU_INIT!` | 重新初始化 IMU | `OK IMU_INIT` 或 `ERR` |
| `#RUN!` | 启动双环控制 | `OK RUN` |
| `#EXP=RUN,id,ms!` | 一键实验运行 | `EXP_START ...` / `OK RUN` |
| `#EXP=STOP,id!` | 停止实验 | `EXP_END ...` / `OK EXP_STOP` |
| `#EXP=DUMP,id!` | 导出实验缓存 | `EXP_DUMP_BEGIN ...` / `OK EXP_DUMP` |
| `#RAW=n!` | 开环原始输出 | `OK RAW` |

---

## 3. 基线检查模板

```text
#VOFA=0!
#STOP!
#IMU_INIT!
#CAL!
#STAT!
```

重点看：

- **[IMU]** `who=0x85`
- **[姿态]** `y`、`yr` 是否正常
- **[编码器]** `el`、`er`、`ed` 是否合理
- **[参数]** `skp/ski/skd/akp/aki/akd/dzl/dzr/sbf/sbv/siv/hdt`

---

## 4. 常用设参模板

### 常规双环

```text
#SPD=1!
#SKP=0.10!
#SKI=0.012!
#SKD=0.00!
#AKP=7.00!
#AKI=0.08!
#AKD=0.35!
#DZ=10!
#DZT=1.0!
#CAL!
#RUN!
```

### 起步偏置专项

```text
#DZL=10!
#DZR=12!
#SBF=2!
#SBV=18!
#SIV=18!
#HDT=400!
#STAT!
#CAL!
#RUN!
```

---

## 5. 起步偏置参数速查

| 参数 | 作用 | 什么时候调 |
| --- | --- | --- |
| `DZL` | 左侧死区补偿 | 左轮晚起转 |
| `DZR` | 右侧死区补偿 | 右轮晚起转 |
| `SBF` | 起步偏置幅值 | 前 0~3s 单侧稳定偏航 |
| `SBV` | 起步偏置退出速度阈值 | 偏置退太早/太晚 |
| `SIV` | 速度积分启用阈值 | 起步猛冲 |
| `HDT` | 航向环延迟介入时间 | 刚起步就被强拉方向 |

### `SBF` 方向

- **[正值]** 补右轮
- **[负值]** 补左轮

---

## 6. 实验采集模板

### 开流 + 运行

```text
#VOFA=0!
#EXP=STREAM,1!
#EXP=RUN,201,10000!
```

### 结束 + 导出

```text
#EXP=STREAM,0!
#EXP=DUMP,201!
```

---

## 7. `STAT` 必看字段

- **[运行]** `run`
- **[偏航]** `y`、`yr`
- **[输出]** `L`、`R`、`OL`、`OR`
- **[编码器]** `el`、`er`、`ed`、`dl`、`dr`、`cl`、`cr`
- **[PID]** `skp`、`ski`、`skd`、`akp`、`aki`、`akd`
- **[起步参数]** `dz`、`dzl`、`dzr`、`dzt`、`sbf`、`sbo`、`sbv`、`siv`、`hdt`
- **[IMU]** `who`、`addr`

---

## 8. 当前不要用的旧命令

- **[不要用]** `#TRIM=...!`
- **[不要用]** `#PWM_MAX=...!`
- **[不要用]** `#DIFF_MAX=...!`
- **[不要用]** `#AT=...!`

原因：当前 `Control.c` 命令入口未实现这些命令。
