# 双环串级 PID 调直指南

## 1. 目标与核心原则

双轮差速小车走直线，本质上依赖两个闭环协同工作：

- **内环：速度环**
  - 目标是让左右电机都能快速、准确、稳定地跟踪目标转速。
- **外环：航向环**
  - 目标是让小车在已经具备稳定速度控制的前提下，持续修正偏航角，保持直线。

一个实用判断标准是：

- **速度环没调好，航向环就是空中楼阁。**
- **航向环没调好，小车就会画龙、跑偏、左右摇摆。**

因此，调试顺序必须坚定执行：

1. 先确认硬件与代码基本正确。
2. 先调速度环，再调航向环。
3. 先解决“能不能稳定跟速”，再解决“能不能走直”。

---

## 2. 调试前提与基本要求

在进入 PID 调参前，先满足以下前提：

### 2.1 硬件前提

- **电机与减速箱状态正常**
  - 左右轮无明显卡滞。
  - 左右轮机械阻力差不要过大。
- **编码器计数方向正确**
  - 给电机正转命令时，测速反馈方向必须一致。
- **IMU 航向读取正常**
  - 静止时角度变化小。
  - 转动车体时角度变化方向正确。
- **电源稳定**
  - 电池压降过大时，速度环稳态误差会增大。

### 2.2 软件前提

- **控制链路方向正确**
  - 速度误差增大时，PWM 输出应朝“补偿误差”的方向变化。
  - 航向误差为正时，差速修正方向必须能把车拉回目标航向。
- **采样周期稳定**
  - 速度环与航向环的运行周期要稳定，不能忽快忽慢。
- **限幅、滤波、积分限幅已具备基础实现**
  - 否则调参结果会被代码缺陷污染。

---

## 3. 总调试策略

建议固定使用下面的顺序：

### 3.1 第一步：先排除非 PID 问题

在调 PID 之前，先确认以下几件事：

- **左右电机裸输出是否基本对称**
  - 同样 PWM 下，两边速度不要差太多。
- **编码器反馈是否可信**
  - 不能出现某一侧明显在转，但编码器几乎不计数。
- **航向修正符号是否正确**
  - 车头向左偏时，控制输出必须推动小车往右纠正，而不是继续往左加剧。
- **输出混控是否合理**
  - 航向差速不能轻易把基础推进量打穿成单侧停轮或反转。

### 3.2 第二步：只调速度环

调速度环时，先尽量不让航向环干扰，目标是验证左右轮都能稳稳跟上目标转速。

### 3.3 第三步：在稳定速度环基础上调航向环

等速度环达标后，再打开航向环做直线修正。

### 3.4 第四步：联调整体表现

两个环单独看都不错后，还要回到整车运动上验证：

- 起步是否顺滑
- 直线是否稳定
- 受扰后能否回正
- 长距离是否持续单侧漂移

---

## 4. 第二阶段：速度环调试策略

### 4.1 目标

速度环的任务是：

- 输入：目标转速 vs 编码器实测转速
- 输出：电机 PWM 占空比

目标是让电机对目标速度做到：

- **响应快**
- **跟踪准**
- **运行稳**

### 4.2 推荐调试顺序

### 4.2.1 先置零 I 和 D

初始设置：

- `Ki = 0`
- `Kd = 0`

只保留比例项，先看系统最基本的响应特性。

### 4.2.2 调 P

逐渐增大 `Kp`，观察速度跟踪响应。

#### 现象判断

- **P 太小**
  - 给了速度指令后，电机起不来或慢吞吞。
  - 遇到小负载后掉速明显。
- **P 合适**
  - 电机能较快接近目标速度。
  - 过渡过程干脆，没有明显高频抖动。
- **P 太大**
  - 目标附近出现高频抖动。
  - 电机发出明显“滋滋”声。
  - 编码器速度在目标值附近频繁来回摆动。

#### 建议

- 先把 `Kp` 调到接近临界振荡，再回退到该值的 **60% - 70%**。
- 速度环一般不需要过于激进，否则容易把编码器测量噪声和电机离散性放大出来。

### 4.2.3 调 I

速度环通常**必须有积分项**，因为实际系统里总会有：

- 摩擦力
- 地面阻力
- 电池压降
- 左右轮轻微负载差异

逐步增大 `Ki`，让系统具备消除稳态误差的能力。

#### 重点观察

- 静止误差是否变小
- 轻捏轮子施加阻力后，速度是否能迅速恢复
- 松手后是否出现明显超调

#### 现象判断

- **I 太小**
  - 总差一点到目标速度。
  - 遇阻后恢复慢。
- **I 合适**
  - 有负载扰动时能较快恢复。
  - 稳态误差小。
- **I 太大**
  - 容易过冲。
  - 出现低频振荡。
  - 松手后会冲过头再回来。

### 4.2.4 关于 D

速度环的 `D` 项通常建议：

- **默认设为 0**

原因：

- 编码器测速本身存在量化噪声。
- 微分项会放大噪声。
- 很容易造成电机高频抖动或啸叫。

只有在测速信号滤波做得非常好时，才考虑引入极小的 `Kd`。

### 4.2.5 速度环达标标准

当速度环满足以下条件时，才建议进入航向环调试：

- **给定目标速度后，能快速达到且无明显超调**
- **手捏轮子施加阻力后，松手能较快恢复速度**
- **左右轮在相同目标下表现一致性较高**
- **没有明显高频异响**

---

## 5. 第三阶段：航向环调试策略

### 5.1 目标

航向环的任务是：

- 输入：目标航向角 vs 当前航向角
- 输出：差速修正量

典型逻辑：

- `左轮目标 = 基础速度 + 航向修正`
- `右轮目标 = 基础速度 - 航向修正`

航向环是在**速度环已经可靠**的基础上，负责把车拉回直线。

### 5.2 推荐调试顺序

### 5.2.1 先置零 I 和 D

初始设置：

- `Ki = 0`
- `Kd = 0`

先只看 `P` 能不能提供正确且有效的回正趋势。

### 5.2.2 调 P：建立回正力度

#### 操作方式

- 小车抬起悬空，手动拨动车体制造角度偏差，观察两轮差速方向。
- 或者放地面低速直行，观察出现偏航后回正是否积极。

#### 现象判断

- **P 太小**
  - 偏了也不怎么修。
  - 车会缓慢越跑越歪。
- **P 合适**
  - 一旦偏离，差速修正能明显把车拉回目标方向。
- **P 太大**
  - 小车像蛇一样左右摆动。
  - 严重时会来回抖动，甚至有原地抽动感。

#### 建议

- 调到“能明显积极回正，但尚未出现明显持续振荡”的临界附近。
- 然后略微回退一点，留出稳定裕度。

### 5.2.3 调 D：增加阻尼、抑制画龙

在 `P` 基本合适后，再逐渐增加 `Kd`。

#### D 项的作用

- 预测偏差变化趋势
- 抑制超调
- 让回正动作更平滑
- 减小左右画龙摆动幅度

#### 现象判断

- **D 太小**
  - 回正时容易左右来回摆。
- **D 合适**
  - 回正过程更利落。
  - 摆动幅度减小。
- **D 太大**
  - 整体变钝。
  - 偏了之后修正反应慢。
  - 像“陷在泥里”一样不愿意动。

#### 注意

- 航向信号若噪声大，`D` 会把噪声放大。
- 必须确保 IMU 输出足够平稳，必要时做低通或融合滤波。

### 5.2.4 调 I：仅用于消除固定方向静差

只有当 `P` 和 `D` 已经调好，而小车仍然**长期稳定地向同一侧偏**时，才考虑加 `Ki`。

#### I 项适用场景

- 左右电机性能不完全一致
- 轮胎、地面、重心存在固定不对称
- 车辆长距离总是向固定方向慢慢漂

#### 使用原则

- **极小幅度增加 `Ki`**
- **必须配合积分限幅**
- **必须监控是否出现低频大摆动**

#### 现象判断

- **I 太小**
  - 固定跑偏依旧难以消除。
- **I 合适**
  - 长距离单侧偏差减小。
- **I 太大**
  - 会出现低频、大幅、慢节奏左右摇摆。
  - 严重时会造成修正过猛，甚至掉头。

### 5.2.5 航向环达标标准

- **轻微受扰后能回到直线**
- **长距离行驶横向偏差可控**
- **没有明显左右画龙**
- **没有持续高频异响**

## 6. 第四阶段：联调与进阶建议

### 6.1 带宽匹配

核心原则：

- **速度环必须比航向环更快、更稳**

如果速度环太慢，会出现：

- 航向环已经发出了差速指令
- 速度环却执行不到位
- 结果就是航向修正失真，整车表现怪异

因此建议：

- 速度环采样频率高于航向环
- 或者至少速度环收敛明显快于航向环

### 6.2 航向输出限幅

航向 PID 输出的是**差速修正量**，一定要限幅。

例如：

- 基础速度较低时，差速修正不能大到足以让一侧直接停轮或反转。
- 否则小车会从“调直”变成“原地拧头”。

实用原则：

- 航向修正量始终应小于基础推进量的一个合理比例。
- 低速时限幅应更保守。

### 6.3 死区处理

建议给航向误差设置一个小死区，例如：

- `±1°` 到 `±2°`

作用：

- 防止小车在走直时因为传感器微小噪声频繁左右微调
- 减少“抽搐感”

### 6.4 动态参数

如果基础 PID 已经稳定，后续可以考虑简单的动态策略：

- **低速时**：航向 `P` 稍小，防止原地抖动
- **高速时**：航向 `P` 稍大，提高抗干扰能力

但这属于后续优化项，不应该在基础 PID 还没调顺之前提前引入。

## 7. 两条必须强调的注意事项

## 7.1 如果调参现象与理论严重不符，先查固件代码逻辑

如果你在调 PID 时遇到这些情况：

- 明明减小 `P`，摆动却更严重
- 明明显著增加回正力度，车却往错误方向修正
- 速度环看起来总是“调不住”
- 航向环一介入就出现单侧停轮、反转、奇怪饱和
- 数据现象与理论判断长期对不上

那么不要先怀疑自己不会调，**要优先怀疑代码逻辑是否存在问题**。

重点检查：

- **误差符号是否写反**
- **角度定义方向是否前后不一致**
- **差速混控方向是否正确**
- **限幅是否把推进量打穿**
- **积分是否有风up**
- **采样周期是否真的按设定执行**
- **编码器和 IMU 数据是否存在解析错误或单位错误**

一句话原则：

- **现象和理论长期不吻合，先查代码，不要盲目加减 PID。**

## 7.2 专注于 PID 调直，不要轻易增加新的变量和参数

当目标只是把双轮差速车调直到能稳定走直时，优先做的是：

- 把现有速度环调稳
- 把现有航向环调顺
- 把必要的限幅、死区、积分限幅做好

不要一遇到问题就马上新增：

- 一堆补偿系数
- 一堆状态变量
- 一堆启发式开关
- 一堆启动偏置参数
- 一堆动态切换阈值

因为这样很容易导致：

- 问题被掩盖，而不是被解决
- 参数数量爆炸，无法定位主因
- 今天看起来好一点，明天又在别的工况翻车

一句话原则：

- **先用尽可能少的变量，把 PID 主链路调顺；只有基础闭环明确受限时，才考虑增加新机制。**

## 8. 常见问题诊断表

| 现象 | 可能原因 | 优先解决方案 |
| :--- | :--- | :--- |
| 小车原地左右抖动 | 航向 `P` 太大；IMU 噪声大 | 减小航向 `P`，检查滤波，增加小死区 |
| 小车走 S 形、画龙 | 航向 `D` 太小；航向 `P` 略大 | 增大航向 `D`，或适当减小航向 `P` |
| 小车长期向同一侧偏 | 机械不对称；航向环缺少适量 `I` | 先查机械一致性，再极小幅引入航向 `I` |
| 电机高频啸叫 | 速度环 `P` 太大；速度环 `D` 过大 | 速度环 `D` 先置 0，降低速度环 `P` |
| 遇到阻力就掉速、跑偏 | 速度环太弱，尤其 `I` 不足 | 适当提高速度环 `I`，验证抗负载恢复能力 |
| 一调 PID 现象就很怪 | 代码逻辑、符号、混控可能有误 | 先检查固件，不要盲目继续调参 |
| 参数越调越多但效果不稳定 | 问题被额外参数掩盖 | 回到最小参数集，重新按顺序调试 |

---

## 9. 推荐实操流程

每次正式调试建议按这个流程执行：

### 9.1 先做静态检查

- 检查编码器方向
- 检查 IMU 方向
- 检查左右轮正转一致性
- 检查串口/日志输出是否可信

### 9.2 只调速度环

- `Ki = 0, Kd = 0`
- 先调 `Kp`
- 再加 `Ki`
- `Kd` 通常保持 `0`

### 9.3 再调航向环

- `Ki = 0, Kd = 0`
- 先调航向 `P`
- 再加少量航向 `D`
- 最后在确有固定偏差时，再极小幅加航向 `I`

### 9.4 最后做整车验证

至少验证以下工况：

- 低速直线
- 中速直线
- 起步阶段
- 长距离直线
- 轻微外力干扰恢复

---

## 10. 最终原则总结

调双轮差速车直线，始终记住下面几句话：

- **先速度，后航向。**
- **先 P，再 I，最后再考虑 D。**
- **速度环的 D 通常为 0。**
- **航向环的 I 要最后上，而且一定要很小。**
- **航向修正必须限幅，不能打穿基础推进。**
- **现象不符合理论时，先查固件逻辑。**
- **专注 PID 调直，不要轻易堆新变量和新参数。**

如果把这几条守住，双环串级 PID 的调试效率会高很多，排障方向也会更清晰。
