# 双环串级 PID 控制器调试标准作业程序（SOP）

## 1. 概述

### 1.1 双环串级 PID 的基本原理

双环串级 PID 由**内环**与**外环**组成。

- **内环**
  - 控制快速变量，如电流、角速度、速度、流量。
  - 目标是快速响应、抑制扰动、稳定执行器。
- **外环**
  - 控制最终目标变量，如位置、姿态角、温度、液位、航向角。
  - 目标是准确跟踪、减小稳态误差，并向内环输出中间设定值。

控制链路如下：

```text
外环设定值 -> 外环 PID -> 内环设定值 -> 内环 PID -> 执行器 -> 被控对象 -> 反馈
```

### 1.2 适用场景说明

适用于存在明显快慢动态分层的对象：

- 电机位置-速度控制
- 平衡车速度-角度控制
- 云台角度-角速度控制
- 温度-功率或温度-流量控制

### 1.3 核心优势分析

- **分层清晰**：先调内环，再调外环，定位问题更直接。
- **抗扰性更强**：内环优先抑制快速扰动。
- **性能更好**：兼顾响应速度、稳定性和精度。
- **可复制性高**：适合标准化调参与批量工程应用。

## 2. 调试前准备

### 2.1 硬件检查清单

| 项目 | 检查内容 | 合格标准 |
| --- | --- | --- |
| 传感器 | 供电、接线、零点、量程 | 输出稳定、无反向 |
| 执行器 | 电机/阀门/加热器动作 | 指令与动作一致，无卡滞 |
| 反馈信号 | 编码器/IMU/温度反馈方向 | 正向控制产生正向反馈 |
| 机械结构 | 松动、偏载、摩擦异常 | 结构可靠、阻力均匀 |
| 急停功能 | 使能断开、急停按钮 | 可立即切断输出 |
| 输出边界 | 死区、最大输出、最小起控量 | 已知且可记录 |

> **安全警告：调试前必须确认反馈方向正确。若反馈极性错误，系统将形成正反馈并迅速失控。**

### 2.2 软件环境配置

- 内环采样频率应高于外环。
- 典型建议：
  - 内环周期 `1~10 ms`
  - 外环周期 `5~50 ms`
- 对噪声信号加入适度滤波，但不得过度增加相位滞后。
- 启用输出限幅、积分限幅、数据记录功能。
- 建议至少记录：设定值、反馈值、误差、PID 三项、输出、饱和标志。

### 2.3 初始参数设定建议

建议初始设置如下：

- 内环：`Kp` 小值，`Ki = 0`，`Kd = 0`
- 外环：`Kp` 小值，`Ki = 0`，`Kd = 0`
- 设定值：从小阶跃开始，不得一开始施加满量程目标

> **安全警告：在未确认输出限幅与急停机制之前，不得直接提高增益或加载大步阶。**

## 3. 调试步骤（核心部分）

### 3.1 双环控制逻辑

调试顺序必须遵循：

1. 先内环，后外环
2. 先 P，后 D，最后 I
3. 先小范围，后大范围
4. 先稳定，再提速

原因：外环把内环当作“被控对象”，内环不稳时外环调参无意义。

### 3.2 PID 数学公式

连续形式：

```text
u(t) = Kp * e(t) + Ki * ∫e(t)dt + Kd * de(t)/dt
```

离散形式：

```text
e[k] = r[k] - y[k]
P[k] = Kp * e[k]
I[k] = I[k-1] + Ki * Ts * e[k]
D[k] = Kd * (e[k] - e[k-1]) / Ts
u[k] = P[k] + I[k] + D[k]
```

输出限幅：

```text
u_raw[k] = P[k] + I[k] + D[k]
u[k] = clamp(u_raw[k], Umin, Umax)
```

条件积分示例：

```text
若 u_raw > Umax 且 e > 0，则暂停积分
若 u_raw < Umin 且 e < 0，则暂停积分
否则允许积分
```

### 3.3 步骤一：内环调试

#### 目标

- 快速响应
- 抑制扰动
- 建立稳定基础闭环

> **安全警告：内环直接作用于执行器，最容易引发高频振荡、过流、过热。必须从小设定值、小增益开始。**

#### 方法

先 `P`，后 `D`，最后 `I`。

#### 操作动作与预期现象

##### A. 确认方向

- **操作动作**
  - 设置 `Ki = 0`、`Kd = 0`
  - 给一个小阶跃目标
- **预期现象**
  - 反馈向目标方向变化
  - 误差逐步减小

若反馈反向扩大，立即停机检查反馈符号或执行器方向。

##### B. 调 `Kp`

- **操作动作**
  - 逐步增加 `Kp`
  - 每次调整后重复同一阶跃测试
- **预期现象**
  - 响应更快
  - 稳态误差减小
  - 超调逐步增加

调整逻辑：

- 响应太慢：增大 `Kp`
- 持续振荡：减小 `Kp`
- 超调偏大但可收敛：记录该值，供 `Kd` 微调参考

##### C. 调 `Kd`

- **操作动作**
  - 在合适 `Kp` 基础上小幅增加 `Kd`
- **预期现象**
  - 超调减小
  - 振荡次数减少
  - 收敛更平顺

调整逻辑：

- 超调大：增大 `Kd`
- 输出噪声或抖动明显：减小 `Kd`

##### D. 调 `Ki`

- **操作动作**
  - 在 `P + D` 已稳定后，小幅加入 `Ki`
- **预期现象**
  - 稳态误差逐步减小
  - 长时间偏差被消除

调整逻辑：

- 有静差：增大 `Ki`
- 出现低频摆动：减小 `Ki`

### 3.4 步骤二：外环调试

#### 目标

- 精准跟踪目标
- 消除稳态误差
- 保持整体平顺稳定

#### 方法

必须在内环已稳定的基础上进行。

#### 带宽匹配原则

```text
外环带宽 <= 内环带宽的 1/3 ~ 1/5
```

或：

```text
外环响应时间 >= 内环响应时间的 3 ~ 5 倍
```

> **安全警告：若外环过快，会频繁改写内环设定值，导致低频摆动、往复修正和整体发飘。**

#### 操作动作与预期现象

##### A. 仅启用外环 `P`

- **操作动作**
  - 设外环 `Ki = 0`、`Kd = 0`
  - 从小 `Kp` 开始
- **预期现象**
  - 系统向目标平稳移动
  - 内环设定值变化连续

调整逻辑：

- 跟踪太慢：增大外环 `Kp`
- 来回摆动：减小外环 `Kp`

##### B. 根据需要加入外环 `D`

- **操作动作**
  - 超调大时，小幅加入 `Kd`
- **预期现象**
  - 接近目标时更平顺
  - 超调减小

##### C. 最后加入外环 `I`

- **操作动作**
  - 在 `P` 或 `P + D` 稳定后逐步增加 `Ki`
- **预期现象**
  - 稳态误差减小
  - 长期偏差被消除

调整逻辑：

- 静差明显：增大 `Ki`
- 低频摆动：减小 `Ki`

### 3.5 步骤三：联调优化

#### 目标

- 微调整体性能
- 处理积分饱和、死区、限幅、噪声问题

> **安全警告：联调时每次仅调整一个参数组，并保留上一版参数。禁止多参数同时大幅修改。**

#### 整体性能微调

- 内环优先关注快速性与阻尼
- 外环优先关注跟踪精度与平顺性
- 若整体发抖，先查内环；若整体发飘，先查外环

#### 抗积分饱和策略

推荐至少采用以下一种：

- 积分限幅
- 条件积分
- 设定值切换时清积分
- 启动阶段禁用积分
- 输出饱和时暂停积分

## 5. 常见问题与故障排查（Troubleshooting）

### 5.1 振荡过大怎么办？

- 降低内环 `Kp`
- 适当增加内环 `Kd`
- 检查采样周期是否过长
- 检查反馈噪声与延迟
- 检查是否存在机械松动或执行器间隙

### 5.2 响应太慢怎么办？

- 适当增加内环 `Kp`
- 检查外环带宽是否设得过低
- 检查输出限幅是否过紧
- 检查执行器是否存在死区或饱和提前出现

### 5.3 存在稳态误差怎么办？

- 适当增加 `Ki`
- 检查是否存在静摩擦、负载偏置或传感器零偏
- 检查积分是否被过早禁止或被限幅过严

### 5.4 输出饱和怎么处理？

- 检查设定值是否过大
- 降低增益或优化目标轨迹
- 增加抗积分饱和逻辑
- 检查执行器能力是否不足

### 5.5 外环一加就不稳怎么办？

- 先确认内环是否真的稳定
- 降低外环 `Kp`
- 延长外环周期
- 保证外环带宽低于内环带宽

## 6. 安全与注意事项

### 6.1 调试过程中的风险控制

- 调试前先验证急停功能。
- 首次上电只允许小阶跃测试。
- 必须启用输出限幅。
- 积分项不得默认无条件开启。
- 大惯量机构、旋转机构、加热系统必须设置独立安全上限。

### 6.2 紧急停止机制

紧急情况包括但不限于：

- 反馈反向扩大
- 输出持续打满
- 高频振荡明显加剧
- 电机过流、过热、异响
- 机构碰撞、失速或偏航失控

发生上述情况时，应立即执行：

1. 切断输出使能
2. 清零积分项
3. 恢复到上一版稳定参数
4. 检查方向、限幅、采样周期和传感器状态

## 7. 调试口诀与最佳实践

### 7.1 调试口诀

```text
先内后外，先P后D再I；
先小后大，先稳后快；
内环求快，外环求准；
有饱和先防积分，有振荡先查方向与带宽。
```

### 7.2 最佳实践

- 每次只改一个参数组。
- 每次试验保留原始数据和参数版本。
- 先解决方向、限幅、死区，再谈性能优化。
- 内环未稳，不调外环。
- 外环发飘，优先降带宽，不要先猛加积分。

# 结论

双环串级 PID 的本质是**用内环保证执行层快速稳定，用外环保证目标层准确可控**。标准整定流程应始终坚持：**方向正确、限幅有效、内环先稳、外环后调、联调渐进、全程留痕**。按本 SOP 执行，可显著提高调试效率、降低试错成本，并减少现场失控风险。
