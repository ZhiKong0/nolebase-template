# 串口调参与运行命令说明

本文说明 `serial_term.py` / 串口助手中常用命令的含义、作用对象与典型用途。

## 一、直接调参数

### `spd=7`
- 含义：设置目标速度，实际对应串口命令 `#SPD=7!`
- 作用：修改 `targetSpeed`
- 用途：控制小车期望前进速度
- 备注：速度越高，偏航误差通常更明显，也更容易暴露左右轮不一致问题

### `trim=-0.0625`
- 含义：设置手动左右轮静态补偿，实际对应 `#TRIM=-0.0625!`
- 作用：给左右轮输出加入固定偏置
- 用途：修正小车天然偏左或偏右的问题
- 经验：
  - `trim < 0`：整体更偏向修正“左轮更快/车体更容易左转”的情况
  - `trim > 0`：整体更偏向修正“右轮更快/车体更容易右转”的情况

### `so=180`
- 含义：设置速度环输出上限，实际对应 `#SO=180!`
- 作用：限制左右轮 PID 输出上限
- 用途：防止输出过猛，影响可控性

### `kpp=2.0`
- 含义：设置速度环 PID 的比例项 `Kp`，对应 `#KPP=2.0!`
- 作用：同时作用于左右轮速度 PID
- 用途：控制速度误差响应快慢

### `kpi=0.2`
- 含义：设置速度环 PID 的积分项 `Ki`，对应 `#KPI=0.2!`
- 作用：同时作用于左右轮速度 PID
- 用途：消除稳态误差

### `kpd=0.0`
- 含义：设置速度环 PID 的微分项 `Kd`，对应 `#KPD=0.0!`
- 作用：同时作用于左右轮速度 PID
- 用途：抑制速度环过冲与振荡

### `hp=...`
- 含义：设置航向控制比例项，实际对应 `#HP=...!`
- 作用：航向误差越大，修正越强
- 用途：控制偏航修正主力度

### `hd=...`
- 含义：设置航向控制微分阻尼项，实际对应 `#HD=...!`
- 作用：基于偏航角速度 `yr` 做抑制
- 用途：减小摇摆、来回摆头

### `hs=...`
- 含义：设置航向相关辅助参数，实际对应 `#HS=...!`
- 用途：当前固件保留该参数接口，便于航向控制拓展/调试

### `db=...`
- 含义：设置航向死区，实际对应 `#DB=...!`
- 作用：误差很小时不进行航向修正
- 用途：减小小误差抖动

### `hi=...`
- 含义：设置航向积分增益，实际对应 `#HI=...!`
- 作用：对持续偏航误差进行积分修正
- 用途：消除长期偏差

### `hil=...`
- 含义：设置航向积分限幅，实际对应 `#HIL=...!`
- 作用：限制航向积分累计量
- 用途：防止积分过大导致失控

### `pwm=150`
- 含义：设置 PWM 最大值，实际对应 `#PWM_MAX=150!`
- 作用：限制左右轮最终输出上限
- 用途：控制整体驱动强度

### `diff=0`
- 含义：设置航向差速限幅，实际对应 `#DIFF_MAX=0!`
- 作用：限制航向修正带来的左右轮输出差
- 用途：避免差速过大导致甩头

### `min=...`
- 含义：设置最小前进 PWM，实际对应 `#MIN=...!`
- 作用：保证低速时电机仍能克服静摩擦启动
- 用途：调低速可观测性时很重要

### `kp=...`
- 含义：设置起步踢一下的 PWM，实际对应 `#KP=...!`
- 用途：帮助小车在起步阶段迅速动起来

### `km=...`
- 含义：设置起步 kick 持续时间，实际对应 `#KM=...!`
- 用途：控制起步辅助维持多久

### `ramp=...`
- 含义：设置 PWM 斜坡步进，实际对应 `#RAMP=...!`
- 作用：限制每次控制更新时 PWM 变化量
- 用途：让起步和修正更平滑

### `at=...`
- 含义：开关自动 trim，实际对应 `#AT=...!`
- `0`：关闭
- `1`：开启

### `at_kp=...`
- 含义：设置自动 trim 比例增益，实际对应 `#AT_KP=...!`
- 用途：自动修正长期左右偏差

### `at_ki=...`
- 含义：设置自动 trim 积分增益，实际对应 `#AT_KI=...!`
- 用途：逐步积累修正量

### `at_lim=...`
- 含义：设置自动 trim 限幅，实际对应 `#AT_LIM=...!`
- 用途：防止自动 trim 修正过大

### `raw=30`
- 含义：直接用固定原始 PWM 驱动电机，实际对应 `#RAW=30!`
- 作用：绕开正常速度环，直接给左右轮输出
- 用途：做底盘、电机、编码器最基础对比测试
- 备注：`raw=0` 可退出原始 PWM 模式

### `bin=3`
- 含义：切换 VOFA 简化数据模式，实际对应 `#BIN=3!`
- 作用：改成更紧凑的数据输出形式
- 用途：需要更轻量高速输出时使用

### `enc_l_sign=1`
- 含义：设置左编码器方向符号，实际对应 `#ENC_L_SIGN=1!`
- 用途：修正左编码器方向正负

### `enc_r_sign=-1`
- 含义：设置右编码器方向符号，实际对应 `#ENC_R_SIGN=-1!`
- 用途：修正右编码器方向正负

## 二、启停 / 状态

### `run`
- 含义：启动小车，实际对应 `#RUN!`
- 作用：正常控制模式开始运行
- 特点：手动 `run` 不带 `exp_id`

### `stop`
- 含义：停止小车，实际对应 `#STOP!`
- 作用：立即停转并清理运行状态

### `stat`
- 含义：主动请求一次状态，实际对应 `#STAT!`
- 用途：查看当前关键状态与参数
- 备注：
  - 手动模式下不带 `exp_id`
  - 实验模式下会带 `exp_id` 与 `t_ms`

### `cal`
- 含义：重新锁定当前航向并清零航向相关积分，实际对应 `#CAL!`
- 用途：跑之前重新校准当前方向

### `hir`
- 含义：清零航向积分项，实际对应 `#HIR!`
- 用途：只想清积分，不重做完整校准时使用

### `at_r`
- 含义：重置自动 trim 累积值，实际对应 `#AT_R!`
- 用途：开始新一轮自动 trim 试验前清空历史积累

## 三、实验 / 运行时长 / 数据流

### `start=117,1200`
- 含义：创建实验上下文，但不立即运行，实际对应 `#EXP=START,117,1200!`
- 参数：
  - `117`：实验 ID
  - `1200`：实验运行时长，单位 ms

### `exp=117,1200`
- 含义：直接创建实验并启动，实际对应 `#EXP=RUN,117,1200!`
- 用途：最常用的定时实验运行命令
- 特点：
  - 会带 `exp_id`
  - 会输出 `CFG` 参数快照
  - 运行时输出 `HB tick=... exp_id=... t_ms=...`

### `estop=117`
- 含义：停止指定实验，实际对应 `#EXP=STOP,117!`
- 用途：提前结束实验

### `dump=117`
- 含义：请求导出指定实验的采样数据，实际对应 `#EXP=DUMP,117!`
- 用途：配合旧 dump 流程导出完整实验表格

### `stream=1`
- 含义：开启实验运行期流式输出，实际对应 `#EXP=STREAM,1!`
- 用途：让实验运行期间持续发用于分析的精简 `HB`

### `stream=0`
- 含义：关闭实验运行期流式输出，实际对应 `#EXP=STREAM,0!`

## 四、推荐测试方法

### 1. 快速手动调参
适合人工多轮测试：

```text
spd=7
trim=-0.0625
so=180
kpp=2.0
kpi=0.2
kpd=0.0
run
stop
stat
```

### 2. 定时实验并保存分析
适合 Python 自动保存/分析：

```text
stream=1
exp=201,1200
```

### 3. 原始电机排障
适合检查电机和编码器方向：

```text
raw=30
raw=0
stat
```

## 五、当前串口输出策略

### 手动 `run`
- 启动时输出一次 `CFG ...`
- 运行期间自动输出精简 `HB ...`
- 不带 `exp_id`
- 空闲时不持续刷屏

### `EXP=RUN`
- 启动时输出一次 `CFG exp_id=... ms=... ...`
- 运行期间每 10ms 输出精简 `HB ... exp_id=... t_ms=...`
- 更适合 Python 自动分析与轨迹重建

### 为什么这样改
目标是让串口只输出真正对调车有用的数据：
- 当前参数配置
- 当前偏航角 `y`
- 偏航角速度 `yr`
- 左右轮 PWM `L/R`
- 左右轮编码器速度 `el/er`
- 速度差 `ed`
- 当前 `trim/at`
- `pmax/dmax`
- `tick/t_ms/exp_id/run`

这样可以减少无关字段，降低串口负担，同时尽量不影响 Python 分析脚本。
