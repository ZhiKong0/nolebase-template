# 小车项目专用《速度环-姿态环/航向环 双环串级 PID 调试标准作业程序（SOP）》

## 1. 概述

### 1.1 本项目双环控制结构

本项目采用**双环串级控制**，并叠加**航向保持/差速修正**，其核心逻辑可概括为：

- **外环：速度环**
  - 输入：目标车速
  - 反馈：实际速度
  - 输出：姿态目标或等效驱动核心量
  - 作用：决定小车“想跑多快”

- **内环：姿态环**
  - 输入：姿态目标
  - 反馈：当前姿态/倾角状态
  - 输出：核心 PWM 驱动量
  - 作用：决定小车“如何稳定地站住并实现驱动”

- **辅助环：航向保持/差速修正**
  - 输入：航向目标或起步锁定的航向参考
  - 反馈：`yaw`
  - 输出：左右轮差速修正量
  - 作用：减少直线行驶偏航，抑制左右轮不一致导致的跑偏

其工程数据流可理解为：

```text
目标速度 -> 速度环 -> 姿态目标 -> 姿态环 -> PWM核心输出
                                    |
                                    +-> 航向保持/差速修正 -> 左右轮差速输出
```

### 1.2 适用场景

本 SOP 适用于当前这类两轮小车/平衡类小车控制系统，尤其适用于以下场景：

- 起步容易向单侧偏转
- 速度环一加就发飘
- 姿态环能站住，但直行跑偏明显
- 左右轮机械或死区存在轻微不对称
- 启动阶段积分或航向保持过早介入，导致抢控制权

### 1.3 核心优势分析

- **优势一：控制职责清晰**
  - 速度环负责“速度目标”
  - 姿态环负责“快速稳定”
  - 航向环负责“直线保持”

- **优势二：便于问题分层定位**
  - 站不住优先查姿态环
  - 速度跟踪差优先查速度环
  - 直行跑偏优先查航向保持、左右死区和启动偏置

- **优势三：更符合本项目当前实现**
  - 已具备 `CFG`、`HB`、`STAT` 观测输出
  - 已具备在线调参入口
  - 已具备启动偏置、左右独立死区、延后积分、延后航向保持逻辑

## 2. 调试前准备

### 2.1 硬件检查清单

| 检查项 | 检查内容 | 合格标准 | 对本项目的意义 |
| --- | --- | --- | --- |
| IMU | 偏航角、姿态角是否稳定 | 静止时漂移可接受 | 否则 `yaw` 判断失真 |
| 编码器左轮 | `el` 是否连续、有数 | 启动后可稳定变化 | 用于速度环与左右一致性判断 |
| 编码器右轮 | `er` 是否连续、有数 | 启动后可稳定变化 | 右轮异常会直接造成跑偏误判 |
| 电机左轮 | 正反转是否正确 | 指令与转向一致 | 防止正反馈或左右反接 |
| 电机右轮 | 正反转是否正确 | 指令与转向一致 | 防止跑偏来自接线错误 |
| 供电 | 电池电压、地线可靠性 | 压降可接受 | 电压塌陷会导致参数判断失真 |
| 机械结构 | 轮胎、轴承、车体重心 | 无明显偏载、无卡滞 | 防止把结构问题误当控制问题 |
| 急停 | 断使能机制 | 可立即停机 | 调试时必须先验证 |

> **安全警告：若编码器、IMU、驱动方向任一项未确认，不得进入 PID 整定。否则会将硬件错误误判为控制参数问题。**

### 2.2 软件环境配置

本项目调试前，至少要确认以下软件条件：

- **采样周期稳定**
  - 内环必须比外环更快。
  - 姿态环是快速闭环，速度环是慢变量闭环。

- **日志观测链路可用**
  - 至少能稳定看到以下关键量：
    - `yaw`
    - `el` / `er`
    - `OL` / `OR`（左右轮最终输出）
    - `sbo`（启动偏置输出）
  - 调参时优先使用当前已接入的 `CFG/HB/STAT` 输出。

- **保护机制开启**
  - 输出限幅有效
  - 启动阶段积分延后有效
  - 航向保持延后有效
  - 左右死区补偿已接入

- **在线调参链路可用**
  - 常规调参优先聚焦：
    - PID 参数
    - `trim`
    - 速度档位
  - 起步诊断阶段可使用以下辅助参数：
    - `DZL` / `DZR`
    - `SBF`
    - `SBV`
    - `SIV`
    - `HDT`

### 2.3 初始参数设定建议

建议初始状态如下：

- **姿态环**
  - 从当前可站立的保守参数开始
  - 若重新整定，则先令 `I=0`、`D` 取保守值或 `0`

- **速度环**
  - 先关闭或极弱化 `I`
  - `P` 从较小值开始
  - 确保其不会一开始就强行拉大姿态目标

- **航向保持**
  - 起步阶段先不要过早介入
  - `HDT` 保持在安全延后值

- **启动补偿**
  - 若当前存在起步单侧偏转，先采用小量补偿，不可一开始给过大偏置

> **安全警告：禁止在姿态环尚未稳定时直接提升速度环或航向保持增益。否则常表现为“刚起步就冲、抖、偏、翻”。**

## 3. 调试步骤（核心部分）

### 3.1 本项目的整定原则

本项目必须按以下顺序调试：

1. **先确认传感器与执行器方向**
2. **先调姿态环，再调速度环**
3. **最后接入航向保持**
4. **起步跑偏先查左右死区与启动偏置，再查航向环**
5. **每次只改一个参数组**

原因如下：

- 姿态环是小车稳定站立的基础。
- 速度环本质上通过改变姿态目标来驱动车体前进。
- 航向保持在本项目中属于叠加修正项，若过早介入，会掩盖姿态环或左右输出不对称的根因。

### 3.2 项目相关控制公式说明

#### 姿态环离散 PID

```text
e_att[k] = ref_att[k] - att[k]
P_att[k] = Kp_att * e_att[k]
I_att[k] = I_att[k-1] + Ki_att * Ts_att * e_att[k]
D_att[k] = Kd_att * (e_att[k] - e_att[k-1]) / Ts_att
u_att[k] = P_att[k] + I_att[k] + D_att[k]
```

#### 速度环离散 PID

```text
e_spd[k] = ref_spd[k] - spd[k]
P_spd[k] = Kp_spd * e_spd[k]
I_spd[k] = I_spd[k-1] + Ki_spd * Ts_spd * e_spd[k]
D_spd[k] = Kd_spd * (e_spd[k] - e_spd[k-1]) / Ts_spd
ref_att[k] = P_spd[k] + I_spd[k] + D_spd[k]
```

#### 航向保持差速修正

```text
e_yaw[k] = ref_yaw[k] - yaw[k]
diff[k] = Kp_yaw * e_yaw[k] + Kd_yaw * (e_yaw[k] - e_yaw[k-1]) / Ts
```

最终左右输出可抽象理解为：

```text
OL = core_pwm - diff + startup_bias_left + deadzone_left_comp
OR = core_pwm + diff + startup_bias_right + deadzone_right_comp
```

其中：

- `core_pwm`：姿态/主控制输出
- `diff`：航向差速修正
- `startup_bias`：起步偏置补偿
- `deadzone_comp`：左右独立死区补偿

### 3.3 步骤一：姿态环调试

#### 目标

- 让小车先具备稳定站立能力
- 响应快，但不过分尖锐
- 抗瞬时扰动能力足够

> **安全警告：姿态环是最内层、最快的控制环，错误参数最容易导致高频抖动、打满输出、车辆摔倒。调试时必须降低速度目标，必要时悬空轮胎或辅助扶持。**

#### 方法

优先顺序：**先 P，后 D，最后 I**。

#### 操作动作与预期现象

##### 阶段 A：只开姿态环 P

- **操作动作**
  - 暂时关闭速度环积分
  - 暂时不让航向保持介入
  - 仅以极小 `Kp_att` 测试小幅摆动恢复能力

- **预期现象**
  - 小车开始表现出基本扶正趋势
  - 倾倒趋势被一定程度抑制

- **调整逻辑**
  - 完全扶不住：增大 `Kp_att`
  - 一加就猛烈抽动：减小 `Kp_att`，同时检查方向和采样延迟

##### 阶段 B：加入姿态环 D

- **操作动作**
  - 在可基本站稳的 `Kp_att` 上，小幅增加 `Kd_att`

- **预期现象**
  - 抖动减少
  - 恢复更干脆
  - 超调减小

- **调整逻辑**
  - 回正慢、发软：适当提高 `Kp_att`
  - 有来回摆头：适当增加 `Kd_att`
  - 高频噪声明显、输出毛刺增多：减小 `Kd_att`

##### 阶段 C：最后决定是否加入姿态环 I

- **操作动作**
  - 仅当姿态环存在可确认的静态偏差时，少量加入 `Ki_att`

- **预期现象**
  - 长期小偏差被修正

- **调整逻辑**
  - 若加入后出现缓慢来回摇摆，优先减小或关闭 `Ki_att`

#### 姿态环合格判据

- 可稳定站住
- 受扰后能快速恢复
- 无持续高频抖动
- 输出不长期打满

### 3.4 步骤二：速度环调试

#### 目标

- 让小车具备稳定、可控的前进速度响应
- 不因速度环过强破坏姿态稳定
- 在小速度段先调通，再扩展到更高速度档

> **安全警告：速度环在本项目中通过改变姿态目标来驱动车体前进。速度环过强时，表象常不是“速度误差大”，而是“车体前后冲、姿态大幅摆、很难站稳”。**

#### 方法

在姿态环已经稳定的基础上，按**P -> I**为主进行整定；若当前实现未突出使用速度 D，则不强求启用。

#### 操作动作与预期现象

##### 阶段 A：只开速度环 P

- **操作动作**
  - 设定低速档位
  - 保持 `Ki_spd = 0`
  - 小步提升 `Kp_spd`

- **预期现象**
  - 小车开始有明确前进意图
  - 速度跟踪能力提高
  - 姿态目标变化仍然平顺

- **调整逻辑**
  - 车不愿意走：增大 `Kp_spd`
  - 车明显前后窜：减小 `Kp_spd`
  - 姿态环突然压力很大：说明速度环过快或目标过大

##### 阶段 B：启用速度积分，但必须延后

- **操作动作**
  - 使用当前固件中的**速度积分启用阈值**逻辑
  - 确保低速起步阶段暂不积分，待速度建立后再积分

- **预期现象**
  - 起步阶段不再因积分堆积而突然猛冲
  - 稳态速度误差逐步减小

- **调整逻辑**
  - 起步前几百毫秒内明显抢控制：提高 `SIV` 或减小 `Ki_spd`
  - 稳定后仍有明显静差：适度增加 `Ki_spd`
  - 中低频前后摆：减小 `Ki_spd`

#### 速度环合格判据

- 低速档可平顺起步
- 不因速度环引发明显姿态振荡
- 速度误差在稳定阶段可接受
- 输出不会在起步阶段长时间打满

### 3.5 步骤三：航向保持/差速修正调试

#### 目标

- 让小车在已稳定前进的基础上尽量直行
- 避免航向保持过早介入抢占起步控制权
- 区分“控制跑偏”与“机械/输出不对称跑偏”

> **安全警告：若起步阶段就强开航向保持，常会把机械不对称、死区差异、左右电机静摩擦差异，伪装成“航向参数问题”。因此本项目必须优先延后航向介入。**

#### 方法

- 先确认不带航向修正时的小车自然偏向
- 再使用延后启用的航向保持
- 调整过程中同步观察 `yaw`、`OL/OR`、`el/er`

#### 操作动作与预期现象

##### 阶段 A：先做无航向强干预基线测试

- **操作动作**
  - 以保守参数起步
  - 记录起步前几秒的：`yaw`、`el`、`er`、`OL`、`OR`、`sbo`

- **预期现象**
  - 若左右基本对称，则航向保持只需轻微修正
  - 若起步立刻单侧偏转，则优先查死区/启动偏置

##### 阶段 B：调整航向延后时间 `HDT`

- **操作动作**
  - 让航向保持在起步若干毫秒后再介入

- **预期现象**
  - 起步更自然
  - 初始离地/克服静摩擦阶段不再出现过度纠偏

- **调整逻辑**
  - 起步刚动就被硬拉回：增大 `HDT`
  - 起步后较长时间无方向约束：减小 `HDT`

##### 阶段 C：微调航向环增益

- **操作动作**
  - 在延后启用有效后，再小幅调整航向增益

- **预期现象**
  - 直线性改善
  - 左右输出差异更合理
  - `yaw` 漂移速度下降

- **调整逻辑**
  - 修正太弱、直线漂移明显：适当增大航向增益
  - 左右轮频繁来回抢差速：减小航向增益

### 3.6 步骤四：起步偏航专用优化

这是本项目的重点步骤，必须单独执行。

#### 优化目标

- 解决起步瞬间单侧偏转
- 避免把“静摩擦不对称”误当成 PID 主参数问题
- 让速度环与航向保持在进入正常工作区前不过早抢控制

#### 推荐调试顺序

```text
DZL / DZR -> SBF -> SBV -> SIV -> HDT
```

#### 各参数的作用与调法

##### 1. `DZL` / `DZR`：左右独立死区

- **操作动作**
  - 先做低速起步测试，观察左右轮谁更难起转
  - 分别调整左、右死区补偿

- **预期现象**
  - 起步时左右轮更接近同时起转
  - `el` / `er` 在起步前段更对称

- **判断依据**
  - 若一侧总是“晚启动”，说明该侧死区补偿可能偏小

##### 2. `SBF`：启动偏置幅值

- **操作动作**
  - 在死区基本对称后，小幅设置启动偏置幅值

- **预期现象**
  - 起步方向性改善
  - `sbo` 在起步期非零，随后逐步退出

- **判断依据**
  - 若起步仍稳定偏向同一侧，可增加合适方向的启动偏置
  - 若起步反向纠偏过度，说明偏置过大

##### 3. `SBV`：启动偏置退出速度阈值

- **操作动作**
  - 调整启动偏置的线性淡出速度阈值

- **预期现象**
  - 偏置只在低速起步阶段存在
  - 一旦车速建立，偏置快速淡出，避免影响中后段直行

- **判断依据**
  - 若中段仍明显受偏置影响：减小作用范围或降低阈值
  - 若起步偏置来不及发挥作用：适度增大阈值

##### 4. `SIV`：速度积分启用阈值

- **操作动作**
  - 将速度积分推迟到车速建立后再开启

- **预期现象**
  - 起步不再因积分堆积出现猛冲或偏冲

- **判断依据**
  - 若刚动就有很强加速冲击：阈值偏低或速度环积分偏强

##### 5. `HDT`：航向保持延迟启用时间

- **操作动作**
  - 航向保持只在起步完成后介入

- **预期现象**
  - 起步不抢控制
  - 中后段开始发挥直线修正作用

- **判断依据**
  - 若起步像被“强拉方向盘”：`HDT` 偏小

### 3.7 推荐观测窗口与判据

建议把调试过程分成两个观察阶段：

#### 阶段一：起步前 0~3 秒

重点观察：

- `yaw` 是否快速单向漂移
- `el` / `er` 是否明显不对称
- `OL` / `OR` 是否一开始就严重失衡
- `sbo` 是否只在起步短时间存在

适用结论：

- **`el/er` 不对称明显**：先查 `DZL/DZR`
- **`OL/OR` 一开始就偏得很大**：先查启动偏置/航向是否介入过早
- **`sbo` 长时间不退出**：查 `SBV`

#### 阶段二：稳定行驶 3 秒后

重点观察：

- `yaw` 漂移速度
- `OL/OR` 长期平均是否失衡
- `el/er` 长期比值是否偏离明显

适用结论：

- **中后段偏航明显**：优先查航向保持增益和触发模式
- **长期左右输出失衡**：查 `trim`、航向增益、机械阻力差异
- **速度稳态误差明显**：查速度环 `Ki`

- 起步是否偏左/偏右
- `yaw` 前 3 秒变化趋势
- `el/er` 起步对称性
- `OL/OR` 是否长期失衡
- 是否存在猛冲、抖动、打满输出

## 5. 常见问题与故障排查（Troubleshooting）

### 5.1 起步就向一侧偏怎么办？

优先顺序：

1. 检查 `el/er` 是否起步即不对称
2. 检查 `DZL/DZR` 是否匹配左右静摩擦差异
3. 检查 `SBF` 是否方向正确、幅值合适
4. 检查 `HDT` 是否过小导致航向过早介入
5. 最后再考虑航向环增益本身

### 5.2 车能站住，但一给速度就前后窜怎么办？

- 速度环 `Kp` 过大
- 速度积分介入过早
- `SIV` 过低
- 姿态环阻尼不足，需补充 `Kd_att`

### 5.3 车能跑，但中后段越来越偏怎么办？

- 航向保持过弱或触发模式不合适
- `trim` 需要微调
- 左右机械阻力长期不一致
- `OL/OR` 长期均值明显失衡

### 5.4 姿态环总是高频抖动怎么办？

- `Kp_att` 过大
- `Kd_att` 对噪声过敏
- 采样延迟或滤波不合理
- IMU 噪声、安装松动或机械共振

### 5.5 输出经常打满怎么办？

- 速度目标过大
- 姿态环或速度环增益过高
- 起步阶段积分累积过多
- 死区过大导致控制长期推不动车轮

### 5.6 为什么不能一开始就调航向参数？

因为本项目大量“跑偏”问题并非都来自航向环，而是来自：

- 左右死区差异
- 启动偏置缺失或方向不对
- 起步阶段速度积分过早介入
- 航向保持延迟不足

若不先排除这些因素，航向环参数会被迫承担本不属于它的补偿任务，后果通常是：

- 起步更乱
- 中后段更飘
- 左右输出频繁抢控制

## 6. 安全与注意事项

### 6.1 调试风险控制

- 首次调参必须使用低速档。
- 必须有人扶车或限制车体运动范围。
- 任何时候发现输出持续打满，应立即停机。
- 不允许同时大幅修改姿态环、速度环、航向环三个参数组。
- 每次测试前记录当前参数，确保可回退。

> **安全警告：对两轮小车而言，最危险的不是“跑不起来”，而是“参数过强导致瞬间冲出、侧翻或高速摆振”。调试时宁可慢，不可猛。**

### 6.2 紧急停止机制

以下任一现象出现，应立刻停机：

- 起步瞬间猛烈单侧偏转
- 姿态高频抖动迅速放大
- 左右输出长期打满
- `yaw` 快速连续单向失控漂移
- 车体出现明显翻倒趋势

停机后按以下顺序处理：

1. 切断电机输出或撤销使能
2. 清积分
3. 恢复上一版稳定参数
4. 复查方向、死区、启动偏置、积分阈值、航向延时

---

## 7. 调试口诀与最佳实践

### 7.1 项目专用调试口诀

```text
先站住，再跑稳，最后再拉直；
先姿态，后速度，再航向；
起步先看死区和偏置，
中后段再看航向和 trim；
积分别早上，航向别早抢。
```

### 7.2 最佳实践

- **先基线测试**
  - 先记录一版不激进修正的真实起步数据，再动参数。

- **先看 0~3 秒，再看 3 秒后**
  - 起步问题和中后段问题常常不是同一个根因。

- **起步问题优先查 `DZL/DZR -> SBF -> SBV -> SIV -> HDT`**
  - 不要直接把所有问题都甩给航向环。

- **常规调参面尽量收敛**
  - 日常只优先调：PID、`trim`、速度档位。
  - 起步保护类参数用于诊断和定型，不建议频繁随意改动。

# 结论

对当前小车项目而言，最有效的整定路径不是“所有参数一起碰”，而是严格按层次处理：

1. **姿态环先站稳**
2. **速度环再跑顺**
3. **航向保持最后拉直**
4. **起步偏航单独用死区、偏置、积分延后、航向延后处理**

只要始终围绕 `yaw`、`el/er`、`OL/OR`、`sbo` 四类观测量进行分段分析，并坚持分层整定、逐项回归，本项目的起步偏转与中后段偏航问题就能被清晰拆解并稳定收敛。
