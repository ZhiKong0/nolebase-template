## MCU 侧改动

### 1. 时间基与串口底层

- `Hardware/Timer.h`
- `Hardware/Timer.c`
- `User/stm32f10x_it.c`
- `Hardware/VOFA.h`
- `Hardware/VOFA.c`

本次新增：

- `Timer_TickISR()`
- `Timer_GetMillis()`
- `Timer_GetMicros()`
- `VOFA_SendBytes()`

其中 `Timer_GetMicros()` 基于 TIM4 的 1MHz 计数结果生成 `timestamp_us`，用于上位机高精度时间对齐。

### 2. 统一二进制遥测协议

接入文件：

- `Hardware/Control.c`
- `Hardware/Control_Track.c`
- `Hardware/Control_Track.h`

两种模式都支持二进制帧输出，帧结构统一为 33 字节：

- `head[2] = 0xAA 0x55`
- `mode[1]`
- `flags[1]`
- `timestamp_us[4]`
- `encoder_left_count[4]`
- `encoder_right_count[4]`
- `yaw_deg[4]`
- `gyro_z_dps[4]`
- `line_bits[1]`
- `line_aux[1]`
- `pwm_left[2]`
- `pwm_right[2]`
- `checksum_xor[1]`
- `tail[2] = 0x0D 0x0A`

说明：

- `mode=0` 表示直线模式，`mode=1` 表示循迹模式。
- `TRACK` 模式下 `line_bits` 为 8 路传感器位图，`line_aux` 为当前激活传感器数量。
- `STRAIGHT` 模式下 `line_bits` 与 `line_aux` 置 0。
- `gyro_z_dps` 优先发送 `gyroZf`，若无有效值则退化为姿态解算角速度。

### 3. 串口命令能力

#### 模式切换

- `#MODE=STRAIGHT!`
- `#MODE=TRACK!`

#### 遥测协议切换

- `#PROTO=TEXT!`
- `#PROTO=BIN!`
- `#BIN=0!`
- `#BIN=9!`
- `#VOFA=0!`
- `#VOFA=9!`

直线模式仍兼容 `JustFloat3/5` 旧方式：

- `#PROTO=JF3!`
- `#PROTO=JF5!`

#### 统一 PID 调参

无论当前后台处于直线模式还是循迹模式，都可以下发：

- `#PID=STRAIGHT,SPEED,kp,ki,kd!`
- `#PID=STRAIGHT,ANGLE,kp,ki,kd!`
- `#PID=TRACK,SPEED,kp,ki,kd!`
- `#PID=TRACK,LINE,kp,ki,kd!`

保留原有兼容命令：

- 直线：`#SKP/#SKI/#SKD/#AKP/#AKI/#AKD/#TS`
- 循迹：`#SKP/#SKI/#SKD/#AKP/#AKI/#AKD/#KP/#KI/#KD/#TS/#PWM_MAX`

### 4. 文本状态命令保持可用

即使遥测切到二进制模式，仍可通过：

- `#STAT!`
- `CFG` 回显

继续读取文本状态，便于现场诊断和参数确认。

### 1. 新链路能力

`trajectory_reconstruction.py` 独立实现了：

- 二进制帧解析
- 时间戳回绕处理
- 编码器增量转速度/角速度
- EKF 状态估计
- 滑动窗口优化
- 轨迹 CSV 输出

### 2. EKF 状态定义

状态向量为：

- `x`
- `y`
- `theta`
- `v`
- `omega`
- `gyro_bias`

观测包含：

- 编码器线速度
- 编码器角速度
- IMU yaw
- IMU gyro_z
- 可选 line sensor 偏差

### 3. 滑窗优化

使用 `scipy.optimize.least_squares` 对最近窗口状态做联合优化，残差包括：

- 相邻状态运动学约束
- yaw 约束
- gyro 约束
- encoder 速度约束
- 可选 line 参考路径约束

### 4. 运行方式

推荐先安装：

```powershell
pip install -r requirements.txt
```

运行：

```powershell
python run_capture.py --config config.yaml
```
