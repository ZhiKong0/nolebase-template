# 小车起步偏航现场调车卡片

## 1. 目标

只处理**起步前 0~3 秒**的问题，优先把以下现象调顺：

- 起步瞬间偏左/偏右
- 刚起步就被航向环强拉
- 起步前几百毫秒猛冲
- 左右轮起转不同步

---

## 2. 只看这 4 组量

每次起步只盯：

- `yaw`
- `el / er`
- `OL / OR`
- `sbo`

判断方法：

- **`el/er` 一开始就不对称**
  - 先调 `DZL / DZR`
- **`OL/OR` 一开始就差很大**
  - 先查 `SBF` 和 `HDT`
- **起步猛冲**
  - 先查 `SIV`
- **`sbo` 退得太慢**
  - 调 `SBV`

---

## 3. 固定调参顺序

```text
DZL / DZR -> SBF -> SBV -> SIV -> HDT
```

禁止一上来先猛调航向主参数。

---

## 4. 现场操作动作

### 步骤 1：先做基线跑

- **操作动作**
  - 上电
  - `#CAL!`
  - `#STAT!`
  - `#RUN!`
  - 只看前 `0~3s`

- **预期现象**
  - 记录偏左还是偏右
  - 记录谁先起转、谁更慢

### 步骤 2：调左右死区 `DZL / DZR`

- **操作动作**
  - 谁起步更慢，就先增加谁的死区补偿
  - 每次只改 `1~2 PWM`

- **预期现象**
  - 左右轮更接近同时起转
  - `el/er` 前段更接近

### 步骤 3：调启动偏置 `SBF`

- **操作动作**
  - 在 `DZL/DZR` 基本对称后，再加小量 `SBF`
  - 每次只改 `1 PWM`

- **预期现象**
  - 起步偏航减轻
  - `sbo` 只在低速前段非零

### 步骤 4：调偏置退出阈值 `SBV`

- **操作动作**
  - 若偏置退太晚，降低 `SBV`
  - 若偏置刚起步就退掉，升高 `SBV`

- **预期现象**
  - 偏置只覆盖起步阶段，不拖到中段

### 步骤 5：调速度积分启用阈值 `SIV`

- **操作动作**
  - 若起步有猛冲/偏冲，增大 `SIV`

- **预期现象**
  - 起步前几百毫秒更平顺
  - 速度积分不再抢控制

### 步骤 6：调航向延迟 `HDT`

- **操作动作**
  - 若起步像被“拉方向盘”，增大 `HDT`

- **预期现象**
  - 起步先自然建立速度
  - 中后段再由航向保持接管

---

## 5. 快速判据

### 情况 A：右轮偏慢

表现：

- `er < el`
- `OR` 不够大
- 车体容易向右偏

优先处理：

```text
DZR↑ -> SBF(补右)↑ -> HDT↑
```

### 情况 B：左轮偏慢

表现：

- `el < er`
- `OL` 不够大
- 车体容易向左偏

优先处理：

```text
DZL↑ -> SBF(补左)调整 -> HDT↑
```

### 情况 C：起步猛冲但不一定偏

表现：

- `OL/OR` 很快拉高
- `actualSpeed` 迅速冲上去

优先处理：

```text
SIV↑ -> 必要时减小速度环 I
```

### 情况 D：起步不偏，但中后段慢慢偏

表现：

- 前 0.5s 正常
- 3s 后开始单侧漂

优先处理：

```text
trim -> 航向增益 -> 长时机械差异
```
