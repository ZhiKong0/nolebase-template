# 双环 PID 调参方法论与流程

> 适用平台：STM32 差速小车 (Project_Refactor-0412)
> 工具：`pid_tuner.py` (v9 评分)
> 串口精度：0.001 (固件 `sscanf("%f")`, Python 端 `:.5f` 格式发送)

---

## 一、系统架构

```
目标速度 ──→ [速度环 PID] ──→ pwmCore (pc)
                                    │
目标航向 ──→ [航向环 PID] ──→ headingDiff (hd)
                                    │
                        ┌───────────┴───────────┐
                        │                       │
                  OL = pc + hd            OR = pc - hd
                  (左轮 PWM)              (右轮 PWM)
                        │                       │
                   [死区 DZ=8]            [死区 DZ=8]
                        │                       │
                     左电机                  右电机
```

### 速度环参数
| 参数 | 串口命令 | 含义 | 典型范围 |
|------|----------|------|----------|
| SKP  | `#SKP=`  | 比例增益 | 0.20 ~ 0.50 |
| SKI  | `#SKI=`  | 积分增益 | 0.005 ~ 0.05 |
| SKD  | `#SKD=`  | 微分增益 | 通常为 0（编码器噪声大，D 项放大噪声） |
| SFF  | `#SFF=`  | 前馈增益 | 1.00 ~ 1.30 |

### 航向环参数
| 参数 | 串口命令 | 含义 | 典型范围 |
|------|----------|------|----------|
| AKP  | `#AKP=`  | 比例增益 | 0.30 ~ 0.80 |
| AKI  | `#AKI=`  | 积分增益 | 0.10 ~ 0.40 |
| AKD  | `#AKD=`  | 微分增益（陀螺仪角速度阻尼） | 0.05 ~ 0.50 |

## 二、评分体系 (v9 strict, 满分 100)

| 维度 | 满分 | 主要惩罚项 |
|------|------|-----------|
| 速度 | 25 | 稳态标差 sstd、超调 sov(>10%)、上升时间 srise(>500ms)、巡航 CV(>10%)、振荡幅度(>1PWM) |
| 航向 | 30 | yaw 漂移率、yaw 最大值、yaw 标差、yaw 积分、hd 饱和率、yaw 偏置 |
| 轨迹 | 25 | 终点横偏、巡航横偏、巡航漂移率、yaw 偏置投影、横向抖动 |
| 平滑 | 20 | 抖动严重度、反转占比、pc slew 变化率 |

### 关键瓶颈对应关系
| 分数低的维度 | 最可能原因 | 首选调整参数 |
|-------------|-----------|-------------|
| 速度分低 | 超调/振荡/上升慢 | SKP、SFF |
| 航向分低 | yaw 积累/漂移/饱和 | AKP、AKI |
| 轨迹分低 | 系统性横偏 | AKI（积分补偿漂移）、AKD（阻尼） |
| 平滑分低 | 电机抖动/反转 | SKP↓、SKD=0 |

## 三、调参总流程（三阶段法）

### 阶段一：粗扫描（确定可行域）

**目标**：用大步长快速排除不可用区域，找到"能跑起来不失稳"的参数范围。

- **测试时长**：10~15 秒
- **步长**：0.05 ~ 0.10
- **每值测试次数**：1 次
- **淘汰标准**：失稳（振荡/偏转>30°/单轮停转）= 直接排除

```bash
# 示例：粗扫 AKP，固定其他参数
python pid_tuner.py --port COM18 --duration 15 --spd 10 \
  --aki 0.200 --akd 0.350 --skp 0.350 --ski 0.020 --skd 0 --sff 1.15 \
  --sweep akp 0.30 0.40 0.50 0.60 0.70
```

**判断规则**：
| 现象 | 判断 | 调整 |
|------|------|------|
| 车剧烈画龙 / hd 饱和 | P 或 D 过大 | 降低 AKP 或 AKD |
| 车缓慢偏移不纠正 | P 和 I 过小 | 增大 AKP 和 AKI |
| 速度严重振荡 | 速度 P 过大或 D 放大噪声 | 降低 SKP，SKD 保持 0 |
| 启动后不动 / 卡顿 | SFF 过低或死区问题 | 增大 SFF |

### 阶段二：细扫描（锁定最优区间）

**目标**：在阶段一确定的可行域内，逐个参数精细扫描。

- **测试时长**：30 秒
- **步长**：0.010 ~ 0.020
- **每值测试次数**：1 次（注意识别启动条件差异）
- **控制变量**：每次**只改一个参数**

```bash
# 示例：细扫 AKD，AKP 已锁定 0.470
python pid_tuner.py --port COM18 --duration 30 --spd 10 \
  --akp 0.470 --aki 0.200 --skp 0.350 --ski 0.020 --skd 0 --sff 1.15 \
  --sweep akd 0.300 0.310 0.320 0.330 0.340 0.350
```

**推荐扫描顺序**（按对得分影响从大到小）：

1. **AKD**（航向 D）→ 影响阻尼/稳定性
2. **AKP**（航向 P）→ 影响纠偏力度
3. **AKI**（航向 I）→ 影响漂移补偿速度
4. **SKP**（速度 P）→ 影响速度响应
5. **SFF**（前馈）→ 影响速度基线
6. **SKI**（速度 I）→ 影响稳态误差

### 阶段三：精细微调（逼近极限）

**目标**：以 0.001 步长，在最优点附近极精细搜索。

- **测试时长**：30 秒
- **步长**：0.001 ~ 0.005
- **每值测试次数**：2~3 次取最高分（排除启动偶发影响）
- **注意**：只在启动 yaw < 0.5° 的测试中比较

```bash
# 示例：0.001 精度微调 AKI
python pid_tuner.py --port COM18 --duration 30 --spd 10 \
  --akp 0.470 --akd 0.320 --skp 0.350 --ski 0.020 --skd 0 --sff 1.15 \
  --sweep aki 0.195 0.198 0.200 0.202 0.205
```

## 四、各参数调大 / 调小的效果速查表

### 4.1 航向环

#### AKP（航向比例）
| 调大 | 调小 |
|------|------|
| ✅ 纠偏更快、横偏更小 | ✅ 更平滑、不易画龙 |
| ❌ 过大→画龙振荡、hd 饱和 | ❌ 过小→偏移积累、轨迹分低 |
| 观察指标：`heading_hd_saturation_pct`、`heading_yaw_std` |

#### AKI（航向积分）
| 调大 | 调小 |
|------|------|
| ✅ 系统性偏移补偿更快 | ✅ 不易积分饱和 |
| ❌ 过大→积分饱和、回弹振荡 | ❌ 过小→持续横偏不纠正 |
| 观察指标：`fr_cruise_lat_drift_rate_mm_s`、`fr_cruise_lat_drift_dir` |

#### AKD（航向微分 = 陀螺仪角速度阻尼）
| 调大 | 调小 |
|------|------|
| ✅ 抑制高频摆动、更稳定 | ✅ 纠偏响应更灵敏 |
| ❌ 过大→过度阻尼、纠偏迟钝 | ❌ 过小→画龙/振荡 |
| 观察指标：`yr_std`(角速度标差)、`traj_max_lateral_vel` |
| **特殊约束**：DZ=8 + core≈10 → 有效差速仅 ±2 PWM，D 过大会占满差速空间 |

### 4.2 速度环

#### SKP（速度比例）
| 调大 | 调小 |
|------|------|
| ✅ 速度响应更快 | ✅ 更平稳 |
| ❌ 过大→速度振荡、pc 剧烈波动 | ❌ 过小→上升时间长 |
| 观察指标：`speed_pc_ss_std`、`speed_rise_time_ms` |

#### SKI（速度积分）
| 调大 | 调小 |
|------|------|
| ✅ 消除稳态速度误差 | ✅ 更稳定 |
| ❌ 过大→积分饱和振荡 | ❌ 过小→稳态有误差 |
| 观察指标：`speed_ss_error_pct`、`fr_cruise_speed_cv` |

#### SKD（速度微分）
| 调大 | 调小 |
|------|------|
| ❌ 放大编码器量化噪声→剧烈振荡 | ✅ 安全 |
| **结论：SKD 应保持 0** |

#### SFF（速度前馈）
| 调大 | 调小 |
|------|------|
| ✅ 启动更快、稳态 PID 负担小 | ✅ PID 完全控制 |
| ❌ 过大→初始超调 | ❌ 过小→上升时间长、稳态 pc 偏高 |
| 观察指标：`speed_overshoot_pct`、`speed_pc_ss_mean` |

## 五、干净启动与数据有效性

### 启动 yaw 的影响
| 启动 yaw | 典型得分影响 | 数据可用性 |
|----------|-------------|-----------|
| < 0.3°  | 无显著影响 | ✅ 可用于参数对比 |
| 0.3°~1.0° | 轨迹分损失 2~5 | ⚠ 可参考，注意标注 |
| 1.0°~3.0° | 轨迹分损失 5~15 | ❌ 不用于参数对比 |
| > 3.0°  | 轨迹分可能归零 | ❌ 废弃，重跑 |

### 如何获得干净启动
1. 车放在平直路面，手动对齐
2. 松手后等 1~2 秒再发 `#RUN!`
3. 开始采集前 IMU 已有约 0.5s 静止校准时间
4. 如果连续 3 次启动 yaw > 1°，检查 IMU 零偏或地面倾斜
