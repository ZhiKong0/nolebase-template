# 三轮小车接线总表（STM32F103C8T6 + TB6612 + MG310(GMR) + ICM42688 / BNO085 + OLED）

> 本表按当前工程代码与接线方案整理：默认 IMU 为 `ICM42688`，使用 `PB12/PB13` 软件 I2C；若后续改用 `BNO085`，也建议优先复用这组 I2C 引脚。

## 1. 电源与地

| 模块端                 | 连接到                  | 说明                |
| ---------------------- | ----------------------- | ------------------- |
| 电池正极               | TB6612 `VM`           | 电机电源（如 7.4V） |
| 电池正极               | 3.3V稳压模块 `VIN+`   | 给逻辑电源降压      |
| 3.3V稳压模块 `VOUT+` | STM32 `3.3V`          | 主控供电            |
| 3.3V稳压模块 `VOUT+` | TB6612 `VCC`          | 驱动逻辑供电        |
| 电池负极               | STM32 `GND`           | 共地                |
| 电池负极               | TB6612 `GND`          | 共地                |
| 电池负极               | 编码器/MPU/OLED `GND` | 全系统共地          |

| `AIN2`    | `PA5`            | 左电机方向 2 |

| `BIN1`    | `PB1`            | 右电机方向 1 |
| `BIN2`    | `PB10`           | 右电机方向 2 |

## 4. ICM42688（软件 I2C）

| ICM42688 引脚 | STM32 引脚     | 说明                                                 |
| ------------- | -------------- | ---------------------------------------------------- |
| `VCC`       | `3.3V`       | 模块供电（以模块规格为准，推荐 3.3V）                |
| `GND`       | `GND`        | 共地                                                 |
| `SCL/SCLK`  | `PB12`       | 软件 I2C SCL                                         |
| `SDA/MOSI`  | `PB13`       | 软件 I2C SDA                                         |
| `ADO/MISO`  | `GND`        | I2C 地址选择：接 GND ->`0x68`，接 3.3V -> `0x69` |
| `CS`        | （悬空或接高） | I2C 模式不用（SPI 模式低有效）                       |
| `INTT`      | （可不接）     | 中断输出1（可接 EXTI）                               |
| `INT2`      | （可不接）     | 中断输出2（可选）                                    |
| `3V3`       | NC             | 3.3V 稳压输出（可不接）                              |
| `NC`        | NC             | 悬空                                                 |

> 建议：`PB12/PB13` 各接一个 4.7k 上拉到 3.3V（若模块板载上拉，可先不外接）。

### 4.1 BNO085（推荐 I2C，作为 ICM42688 替换方案）

| BNO085 引脚 | STM32 引脚（推荐）       | 说明                                   |
| ----------- | ------------------------ | -------------------------------------- |
| `VDD`     | `3.3V`                 | 模块供电，严禁直接接 5V                |
| `GND`     | `GND`                  | 共地                                   |
| `SCL`     | `PB12`                 | 推荐复用当前 IMU 的 I2C 时钟脚         |
| `SDA`     | `PB13`                 | 推荐复用当前 IMU 的 I2C 数据脚         |
| `INT`     | `PA15` 或任意空闲 GPIO | 数据就绪中断，建议连接                 |
| `RST`     | `PB14` 或任意空闲 GPIO | 软件复位，建议接可控 GPIO              |
| `ADDR`    | `GND` 或 `3.3V`      | 地址选择：`GND -> 0x28`，`3.3V -> 0x29` |
| `PS0`     | `GND`                  | I2C 模式选择                           |
| `PS1`     | `3.3V`                 | I2C 模式选择                           |

> 推荐替换方式：直接把原 `ICM42688` 的 `PB12/PB13` 改接到 `BNO085` 的 `SCL/SDA`，这样改线最少。
>
> 注意：如果你仍保留当前蓝牙接线，则不要把 `PB14` 固定给 `BNO085_RST`，因为 `PB14/PB15` 目前在总表中预留给软件串口蓝牙，`RST` 可以改接其他空闲 GPIO。

## 7. 按键模块

| 按键     | STM32 引脚 | 功能                          |
| -------- | ---------- | ----------------------------- |
| `按键` | `PB5`    | 短按=启动/停止，长按=切换速度 |

**接线方式（上拉输入模式）：**

```
按键: 一端接PB5，另一端接GND

短按（<1秒）= 启动/停止电机
长按（≥1秒）= 切换速度档位

按下时 = 低电平（触发）
松开时 = 高电平（内部上拉）
```

## 8. 74HC4051 8通道模拟多路选择器模块

| 74HC4051 模块丝印 | 芯片功能 | 接线目标 | 关键说明 |
| :--- | :--- | :--- | :--- |
| **VCC** | 正电源 | **3.3V** | 供电电压，与STM32逻辑电平一致 |
| **GND** | 电源地 | **STM32 GND** | **必须共地**！否则电平错乱无法工作 |
| **VEE** | 模拟负电源 | **GND** | 数字应用时接地 |
| **E** | 使能端（低有效） | **GND** | 接地=始终使能，省一个IO口 |
| **S0** | 地址位0 | **STM32 PA2** | 通道选择最低位 |
| **S1** | 地址位1 | **STM32 PA11** | 通道选择中间位 |
| **S2** | 地址位2 | **STM32 PA10** | 通道选择最高位 |
| **Z** | 公共输入/输出 | **STM32 PA3** | 上拉输入，读取选中通道的数据 |
| **Y0** | 通道0 | **12路循迹模块 - A3** | 第1路信号（最左） |
| **Y1** | 通道1 | **12路循迹模块 - A4** | 第2路信号 |
| **Y2** | 通道2 | **12路循迹模块 - A5** | 第3路信号（L1） |
| **Y3** | 通道3 | **12路循迹模块 - A6** | 第4路信号（L0） |
| **Y4** | 通道4 | **12路循迹模块 - A7** | 第5路信号（M中间） |
| **Y5** | 通道5 | **12路循迹模块 - A8** | 第6路信号（R0） |
| **Y6** | 通道6 | **12路循迹模块 - A9** | 第7路信号（R1） |
| **Y7** | 通道7 | **12路循迹模块 - A10** | 第8路信号（最右） |

### 8.1 工作原理

1. **选择通道**：通过S0~S2三位地址码选择Y0~Y7中的某一路
2. **读取数据**：被选中的通道与Z引脚导通，STM32读取PA3(Z)即可获得该路传感器状态
3. **循环扫描**：依次切换S0~S2选择8个通道，逐路读取，组合成8位传感器数据

### 8.2 12路循迹模块接线（实际使用A3~A10八路）

| 12路循迹模块引脚 | 连接到 | 说明 |
| ---------------- | ---------- | ---- |
| `VCC`          | `3.3V`     | 模块供电 |
| `GND`          | `GND`      | 必须共地 |
| `A3`           | `74HC4051 Y0` | 第1路信号（最左） |
| `A4`           | `74HC4051 Y1` | 第2路信号 |
| `A5`           | `74HC4051 Y2` | 第3路信号（L1） |
| `A6`           | `74HC4051 Y3` | 第4路信号（L0） |
| `A7`           | `74HC4051 Y4` | 第5路信号（M中间） |
| `A8`           | `74HC4051 Y5` | 第6路信号（R0） |
| `A9`           | `74HC4051 Y6` | 第7路信号（R1） |
| `A10`          | `74HC4051 Y7` | 第8路信号（最右） |
| `A0`~`A2`      | 不接        | 未使用 |
| `A11`          | 不接        | 未使用 |

## 9. 上电前检查

| 检查项    | 标准                                                                    |
| --------- | ----------------------------------------------------------------------- |
| 共地      | 电池负极、STM32 GND、TB6612 GND、编码器 GND、ICM/BNO GND、OLED GND、74HC4051 GND、12路循迹 GND 全部连通 |
| 逻辑电压  | STM32/TB6612 VCC/编码器/ICM/BNO/OLED 都是 3.3V                              |
| STBY 逻辑 | `PB0=0` 电机不转，`PB0=1` 才允许驱动                                |
| BNO085 模式脚 | 若使用 BNO085 的 I2C，推荐 `PS0=0`、`PS1=1`，且 `ADDR` 不要悬空        |
| 74HC4051 供电 | VCC 接 3.3V，GND 接 GND，VEE 接 GND，E 接 GND（始终使能）                |
| 12路循迹供电 | 模块供电接 `3.3V`，与74HC4051逻辑电平一致，实际使用A3~A10八路              |
| 74HC4051 地址 | S0(PA2)、S1(PA11)、S2(PA10) 为推挽输出，Z(PA3) 为上拉输入                 |
