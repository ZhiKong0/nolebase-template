# 三轮小车接线总表（STM32F103C8T6 + TB6612 + MG310(GMR) + BNO085 + OLED）

> 本表用于把当前工程中的姿态传感器由 `ICM42688` 更换为 `BNO085` 时的接线整理。BNO085 可通过 `I2C` 或 `UART` 与 STM32 通信，推荐优先使用 `I2C`，便于与当前小车工程习惯保持一致。

## 1. 接线前的重要准备

| 检查项   | 要求                | 说明                                                 |
| -------- | ------------------- | ---------------------------------------------------- |
| 工作电压 | `3.3V`            | BNO085 为 3.3V 逻辑器件，严禁直接接 5V               |
| 共地     | 必须共地            | STM32、BNO085、驱动、电源地必须连通                  |
| 模式选择 | 由 `PS0/PS1` 决定 | 上电时锁定接口模式，接错会导致无法通信               |
| I2C 上拉 | 需要                | `SCL`、`SDA` 建议各接 `4.7kΩ` 上拉到 `3.3V` |
| 复位控制 | 推荐预留            | `RST` 可接一个 GPIO，便于异常时软件复位            |
| 中断脚   | 推荐连接            | `INT` 接 GPIO/EXTI，便于数据就绪通知               |

## 2. BNO085 模式选择说明

> `PS0`、`PS1` 的组合请以你手上的 **BNO085 模块原理图/手册** 为准，不同模块板丝印可能略有差异。下面按你给出的常见接法整理。

| 通信方式 | `PS0` | `PS1` | 说明                                  |
| -------- | ------- | ------- | ------------------------------------- |
| `I2C`  | `0`   | `1`   | 最常用，适合 STM32 主控轮询或中断读取 |
| `UART` | `1`   | `0`   | 适合独立串口通信                      |

### 推荐做法

- **[I2C 推荐]** 若你准备替换当前工程里的陀螺仪，优先用 `I2C`
- **[上电固定]** `PS0/PS1` 不要悬空，直接固定到 `GND` 或 `3.3V`
- **[查模块资料]** 若你的模块已经板载模式电阻或焊盘开关，按模块说明优先

## 3. 方式一：BNO085 使用 I2C 通信（推荐）

### 3.1 推荐接线表

| BNO085 引脚 | STM32 引脚（示例）       | 说明                              |
| ----------- | ------------------------ | --------------------------------- |
| `VDD`     | `3.3V`                 | 传感器供电，严禁接 5V             |
| `GND`     | `GND`                  | 地线，必须共地                    |
| `SCL`     | `PB12`                 | 推荐沿用当前工程陀螺仪 I2C 时钟脚 |
| `SDA`     | `PB13`                 | 推荐沿用当前工程陀螺仪 I2C 数据脚 |
| `INT`     | `PA15` 或任意空闲 GPIO | 数据就绪中断，建议接 EXTI         |
| `RST`     | `PB14` 或任意空闲 GPIO | 复位脚，建议接可控 GPIO           |
| `ADDR`    | `GND` 或 `3.3V`      | 设备地址选择，上电后锁定·GND·   |
| `PS0`     | `GND`                  | I2C 模式选择                      |
| `PS1`     | `GND`                  | I2C 模式选择                      |

### 3.2 I2C 地址说明

| `ADDR` 电平 | 7 位地址 | HAL 中常见写法（左移 1 位） |
| ------------- | -------- | --------------------------- |
| `GND`       | `0x28` | `0x50`                    |
| `3.3V`      | `0x29` | `0x52`                    |

### 3.3 I2C 额外硬件要求

- **[上拉电阻]** `SCL`、`SDA` 各接一个 `4.7kΩ` 到 `3.3V`
- **[线长]** 线尽量短，避免与电机线平行布线太长
- **[供电去耦]** 模块电源附近建议有去耦电容
- **[INT 可选]** 如果前期只做验证，也可以先不接 `INT`，仅用轮询读取

### 3.4 与你当前工程最接近的 I2C 替换方案

当前旧接线总表里，ICM42688 使用：

- `PB12` -> 传感器 `SCL`
- `PB13` -> 传感器 `SDA`

如果你要最少改动地替换成 BNO085，建议先这样接：

| 原 ICM42688                | 改成 BNO085               |
| -------------------------- | ------------------------- |
| `PB12 -> ICM_SCL`        | `PB12 -> BNO085_SCL`    |
| `PB13 -> ICM_SDA`        | `PB13 -> BNO085_SDA`    |
| 原先 IMU 供电 `3.3V/GND` | 继续接 BNO085 `VDD/GND` |
| 原先无中断脚               | 可新增 `INT -> PA15`    |
| 原先无复位脚               | 可新增 `RST -> PB14`    |

这样改线最简单，后续软件里主要替换的就是 IMU 驱动层。

## 4. 方式二：BNO085 使用 UART 通信

### 4.1 推荐接线表

| BNO085 引脚 | STM32 引脚（示例）       | 说明                |
| ----------- | ------------------------ | ------------------- |
| `VDD`     | `3.3V`                 | 供电                |
| `GND`     | `GND`                  | 共地                |
| `TX`      | `PA3` 或其它 USARTx_RX | BNO085 发，STM32 收 |
| `RX`      | `PA2` 或其它 USARTx_TX | BNO085 收，STM32 发 |
| `INT`     | 任意 GPIO                | 可选中断通知        |
| `RST`     | 任意 GPIO                | 推荐接复位控制      |
| `PS0`     | `3.3V`                 | UART 模式选择       |
| `PS1`     | `GND`                  | UART 模式选择       |

### 4.2 UART 接线注意事项

- **[TX/RX 交叉]** `BNO085_TX -> STM32_RX`，`BNO085_RX -> STM32_TX`
- **[串口冲突]** 若你当前 `PA2/PA3` 已用于 `USART2` 串口调参，则不要直接占用，避免和 VOFA+/USB-TTL 冲突
- **[更推荐独立串口]** 若用 UART 接 BNO085，建议换到另一个空闲串口或软串口方案
- **[优先级]** 对你当前工程而言，UART 方式通常不如 I2C 方便，因为会挤占调参串口资源

## 5. 接线总表怎么改

如果你要把原来的 `ICM42688` 改成 `BNO085`，建议把总表中的 IMU 部分替换成下面这版。

### 5.1 替换后的 IMU 接线块（推荐 I2C 版）

| BNO085 引脚 | STM32 引脚 | 说明                    |
| ----------- | ---------- | ----------------------- |
| `VDD`     | `3.3V`   | 模块供电                |
| `GND`     | `GND`    | 共地                    |
| `SCL`     | `PB12`   | BNO085 I2C 时钟         |
| `SDA`     | `PB13`   | BNO085 I2C 数据         |
| `INT`     | `PA15`   | 数据就绪中断，建议连接  |
| `RST`     | `PB14`   | 软件复位，建议连接      |
| `ADDR`    | `GND`    | I2C 地址固定为 `0x28` |
| `PS0`     | `GND`    | I2C 模式                |
| `PS1`     | `3.3V`   | I2C 模式                |

## 6. STM32 引脚占用变化建议

若采用 **I2C 方案**，建议引脚占用更新为：

| STM32 引脚 | 新用途         |
| ---------- | -------------- |
| `PB12`   | `BNO085_SCL` |
| `PB13`   | `BNO085_SDA` |
| `PA15`   | `BNO085_INT` |
| `PB14`   | `BNO085_RST` |

### 说明

- `PB12/PB13`：继续沿用当前 IMU 的 I2C 位置，改动最小
- `PA15/PB14`：作为推荐新增控制脚；如果你板子布线不方便，也可以先不接 `INT/RST`
- 若 `PA15/PB14` 已被你别的模块占用，可换成任何空闲 GPIO，只要软件同步修改即可

## 7. 不推荐直接照搬 UART 的原因

你的当前小车工程里：

- `PA2/PA3` 已用于 `USART2` 串口调参
- VOFA+ / 上位机脚本也依赖这组串口

如果 BNO085 改走 UART，而你又占用了 `PA2/PA3`，就会和现有调参链路冲突。除非你准备同步重构串口资源，否则更建议：

- **[首选]** BNO085 走 `I2C`
- **[保留]** `USART2` 继续用于调参、日志、实验控制

## 8. 上电前检查清单

| 检查项   | 标准                                                 |
| -------- | ---------------------------------------------------- |
| 电压     | `BNO085_VDD = 3.3V`                                |
| 共地     | `STM32 GND` 与 `BNO085 GND` 必须连通             |
| 模式脚   | I2C 时 `PS0=0, PS1=1`；UART 时 `PS0=1, PS1=0`    |
| 地址脚   | I2C 时 `ADDR` 固定接 `GND` 或 `3.3V`，不要悬空 |
| 上拉     | I2C 的 `SCL/SDA` 有无上拉到 `3.3V`               |
| 串口冲突 | 若用 UART，确认不占用当前调参串口                    |
| 中断脚   | `INT` 若接入，确认对应 GPIO 支持输入/EXTI          |
| 复位脚   | `RST` 若接入，确认上电默认电平正确                 |

## 9. 最终推荐

### 推荐方案

- **[接口选择]** `I2C`
- **[模式脚]** `PS0 -> GND`，`PS1 -> 3.3V`
- **[地址脚]** `ADDR -> GND`，地址固定 `0x28`
- **[STM32 接线]** `PB12/PB13` 保持为 IMU I2C
- **[可选增强]** `INT -> PA15`，`RST -> PB14`

### 推荐原因

- **[改线最少]** 可以直接替换当前 ICM42688 的 I2C 位置
- **[保留调参链路]** 不影响 `USART2` 的 VOFA+/串口实验
- **[后续迁移方便]** 软件侧主要替换 IMU 驱动，不必大改整车通信结构

## 10. 备注

- **[务必核实]** 不同 BNO085 模块的 `PS0/PS1/ADDR/RST/INT` 丝印和默认上拉方式可能不同，最终请以你手上模块原理图为准
- **[若模块已带上拉]** I2C 外部 4.7k 上拉可视情况省略
