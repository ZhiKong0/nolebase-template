# 三轮小车接线总表（STM32F103C8T6 + TB6612 + MG310(GMR) + MPU6050 + OLED）

> 本表按当前工程代码与接线方案整理：MPU6050 使用 `PB12/PB13` 软件 I2C，串口调参使用 `USART2 (PA2/PA3)`。

## 1. 电源与地

| 模块端              | 连接到                | 说明           |
| ---------------- | ------------------ | ------------ |
| 电池正极             | TB6612 `VM`        | 电机电源（如 7.4V） |
| 电池正极             | 3.3V稳压模块 `VIN+`    | 给逻辑电源降压      |
| 3.3V稳压模块 `VOUT+` | STM32 `3.3V`       | 主控供电         |
| 3.3V稳压模块 `VOUT+` | TB6612 `VCC`       | 驱动逻辑供电       |
| 电池负极             | STM32 `GND`        | 共地           |
| 电池负极             | TB6612 `GND`       | 共地           |
| 电池负极             | 编码器/MPU/OLED `GND` | 全系统共地        |

## 2. TB6612 ↔ STM32

| TB6612 引脚 | STM32 引脚         | 用途      |
| --------- | ---------------- | ------- |
| `STBY`    | `PB0`            | 驱动使能    |
| `PWMA`    | `PA8 (TIM1_CH1)` | 左电机 PWM |
| `AIN1`    | `PA4`            | 左电机方向 1 |
| `AIN2`    | `PA5`            | 左电机方向 2 |
| `PWMB`    | `PA9 (TIM1_CH2)` | 右电机 PWM |
| `BIN1`    | `PB1`            | 右电机方向 1 |
| `BIN2`    | `PB10`           | 右电机方向 2 |

## 3. 电机与编码器（MG310）

### 3.1 左轮（电机 A）

| MG310-A 引脚        | 连接到              | 说明       |
| ----------------- | ---------------- | -------- |
| `1 (Motor+)`      | TB6612 `AO1`     | 电机线      |
| `6 (Motor-)`      | TB6612 `AO2`     | 电机线      |
| `5 (Encoder VCC)` | STM32 `3.3V`     | 编码器供电    |
| `2 (Encoder GND)` | STM32 `GND`      | 编码器地     |
| `4 (Encoder A)`   | `PA0 (TIM2_CH1)` | 左编码器 A 相 |
| `3 (Encoder B)`   | `PA1 (TIM2_CH2)` | 左编码器 B 相 |

### 3.2 右轮（电机 B）

| MG310-B 引脚 | 连接到 | 说明 |
|---|---|---|
| `1 (Motor+)` | TB6612 `BO1` | 电机线 |
| `6 (Motor-)` | TB6612 `BO2` | 电机线 |
| `5 (Encoder VCC)` | STM32 `3.3V` | 编码器供电 |
| `2 (Encoder GND)` | STM32 `GND` | 编码器地 |
| `4 (Encoder A)` | `PA6 (TIM3_CH1)` | 右编码器 A 相 |
| `3 (Encoder B)` | `PA7 (TIM3_CH2)` | 右编码器 B 相 |

## 4. MPU6050（软件 I2C）

| MPU6050 引脚 | STM32 引脚 | 说明            |
| ---------- | -------- | ------------- |
| `VCC`      | `3.3V`   | 建议 3.3V 供电    |
| `GND`      | `GND`    | 共地            |
| `SCL`      | `PB12`   | 软件 I2C SCL    |
| `SDA`      | `PB13`   | 软件 I2C SDA    |
| `AD0`      | `GND`    | I2C 地址 `0x68` |
| `INT`      | （可不接）    | 后续可接 EXTI     |

> 建议：`PB12/PB13` 各接一个 4.7k 上拉到 3.3V（若模块板载上拉，可先不外接）。

## 5. OLED（软件 I2C）

| OLED 引脚 | STM32 引脚 | 说明 |
|---|---|---|
| `VCC` | `3.3V` | 供电 |
| `GND` | `GND` | 地 |
| `SCL` | `PB7` | 软件 I2C SCL |
| `SDA` | `PB8` | 软件 I2C SDA |

## 6. 串口调参（USART2）

| 功能 | STM32 引脚 | 连接对象 |
|---|---|---|
| `USART2_TX` | `PA2` | USB-TTL `RX` |
| `USART2_RX` | `PA3` | USB-TTL `TX` |
| `GND` | `GND` | USB-TTL `GND` |

## 7. STM32 引脚占用总览

| STM32 引脚 | 信号/模块 |
|---|---|
| `PA0` | 编码器左 A（TIM2_CH1） |
| `PA1` | 编码器左 B（TIM2_CH2） |
| `PA2` | USART2_TX（USB-TTL/VOFA+） |
| `PA3` | USART2_RX（USB-TTL/VOFA+） |
| `PA4` | AIN1 |
| `PA5` | AIN2 |
| `PA6` | 编码器右 A（TIM3_CH1） |
| `PA7` | 编码器右 B（TIM3_CH2） |
| `PA8` | PWMA（TIM1_CH1） |
| `PA9` | PWMB（TIM1_CH2） |
| `PB0` | STBY |
| `PB1` | BIN1 |
| `PB5` | 按键1（启动/停止） |
| `PB6` | 按键2（切换速度） |
| `PB7` | OLED_SCL |
| `PB8` | OLED_SDA |
| `PB10` | BIN2 |
| `PB12` | MPU6050_SCL |
| `PB13` | MPU6050_SDA |
| `PB14` | 软件串口 TX（蓝牙 HC-05/06） |
| `PB15` | 软件串口 RX（蓝牙 HC-05/06） |

## 8. 按键模块

| 按键 | STM32 引脚 | 功能 |
|---|---|---|
| `按键` | `PB5` | 短按=启动/停止，长按=切换速度 |

**接线方式（上拉输入模式）：**

```
按键: 一端接PB5，另一端接GND

短按（<1秒）= 启动/停止电机
长按（≥1秒）= 切换速度档位

按下时 = 低电平（触发）
松开时 = 高电平（内部上拉）
```

## 9. 蓝牙模块（HC-05/HC-06）

| HC-05/HC-06 引脚 | STM32 引脚 | 说明 |
|---|---|---|
| `VCC` | `3.3V` | 供电（HC-06支持3.3V，HC-05建议5V） |
| `GND` | `GND` | 共地 |
| `TXD` | `PB15` | 软件串口 RX |
| `RXD` | `PB14` | 软件串口 TX |

> **注意**：PB14/PB15 原为 JTAG 引脚，已在代码中禁用 JTAG 释放这两个引脚。

## 9. 上电前检查

| 检查项 | 标准 |
|---|---|
| 共地 | 电池负极、STM32 GND、TB6612 GND、编码器 GND、MPU GND、OLED GND 全部连通 |
| 逻辑电压 | STM32/TB6612 VCC/编码器/MPU/OLED 都是 3.3V |
| STBY 逻辑 | `PB0=0` 电机不转，`PB0=1` 才允许驱动 |
| 串口线序 | PA2→TTL-RX，PA3→TTL-TX，不能接反 |
